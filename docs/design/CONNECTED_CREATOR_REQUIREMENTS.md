> **当前实现与实际验收**：[2026-10-10 状态说明](../CONNECTED_CREATOR_STATUS.md)。本地 RAG、案例研究与多模型配置已接入；本人小红书账号已接入本机 MCP 有限轮询，非全量或实时推送。当前验收在 8775 独立环境，默认数据库存在 SCHEMA_TOO_NEW 版本不匹配，不能称默认启动已通过。

版本：2026-10-10；状态：用户已批准实施，本文为目标与验收契约，不是功能完成证明。

## 1. 优先级和实施顺序

项目优先服务小红书个人账号，用户没有开放平台接口权限。最终体验为：用户登录本项目、连接自己的小红书账号后，数据自动持续同步；页面展示数据更新时间、来源采集时间及实际延迟。保留已有内容试飞台、风洞、四角色创作、抖音兼容和人工确认，不扩展自动发布。

先统一全部当前 AI 参考资料，再开展代码实现。依次推进：接入可行性验证 → 数据连接与模型配置基础 → 可选来源研究及混合 RAG → 四角色闭环验收。不同模块可在接口约定后并行，不以文档承诺代替数据渠道实测。

## 2. 小红书连接和自动同步

**当前用户授权（2026-10-10后续增补）**：用户明确授权非商业本人账号读取及有限公开案例研究，并亲自完成登录。已接入本机MCP有限轮询；新增已绑定账号网页二维码重连、持久评论分页、本人笔记显式导入RAG以及xhs_local有限站内视频文字描述研究。本轮扫码重连后站内研究已完成3份资料采集、报告下载及检索。后续用户明确授权定时读取创作者首页与笔记管理，新增只读DOM通道已完成真实读取器验证，Worker入库及页面联调待验收；原MCP评论通道保持独立。全量评论、单篇曝光、实时推送仍未完成。自有媒体本地转写已通过网页上传、人工校对与检索，不能据此宣称已取得平台视频音轨。

先前方案将“必须先取得官方接口权限”设为此次实施前置条件，已按用户后续具体授权修订，不能继续以旧段落拒绝本人有限读取。本轮授权不代表平台官方API许可，也不提供商业多租户数据转售许可。始终不实施绕限制采集：遇验证码、登录失效、付费墙或访问控制停止，由用户完成官方交互；不发布、关注或互动。

历史条款核对（2026-10-10）：[创作服务平台协议](https://agree.xiaohongshu.com/h5/terms/ZXXY20260422001/-1)（2026-04-24更新）的自动访问、技术抓取与再利用限制，以及[官方scope](https://openaccount.xiaohongshu.com/docs/scope)仅basic_info开放、read_notes规划中的记录继续保留。具体适用范围与工程授权分别记录，不把登录身份当成官方笔记、评论或流量接口授权。

优先产品流程：网站登录 → 选择账号 → 连接小红书 → 用户在官方页面扫码/登录 → 后端确认身份绑定 → 开启只读同步 → 展示连接状态与更新时间。Cookie、密码和恢复码不进入日志、导出文档或模型上下文；登录会话按 owner/account_id 隔离，断开连接撤销后续任务。

公开笔记/点赞/收藏/评论与创作者后台的曝光/阅读/播放分别验证。字段不可得为 null 并说明原因；不以点赞代替流量，不将手工回填升级为平台核验。保存内容 ID、评论 ID、父评论 ID、来源 URL、来源时间、采集时间、来源方式、授权范围和原始证据引用；去重、增量游标、失败重试、授权过期、限流退避、取消和重启恢复均可审计。

实时同步是最终体验目标。只有源提供推送且实测后才称实时推送；轮询标注自动同步与实际间隔，显示延迟和最后成功时间。本机连接器依赖电脑与服务在线；休眠、断网、验证码触发时显示暂停原因。不能将网页刷新当成平台数据更新。

验收：同一真实授权账号的笔记及评论入库，连续两次同步识别新增或变化且无重复；能逐项对照后台流量字段；断线/重启恢复、取消、用户隔离通过。未验证字段和平台限制保留在差距清单，不用模拟数据满足此门槛。

## 3. 可选联网来源与案例文档

用户可选择小红书、京东、淘宝/天猫、品牌官网、百度或全网等来源。目标平台与搜索提供商分开配置；站点限定搜索必须标明覆盖有限，不伪装成平台全量搜索。授权任务包含关键词、时间范围、条数上限、来源白名单、同步频率及费用上限。授权后允许编排器自动搜索、读取、入库和持续同步；未授权任务仍默认关闭联网工具。

美妆场景：输入赛道和产品 → 搜索同类内容 → 去重筛选高互动候选 → 读取正文或合法可得的视频字幕/转写 → 分析结构 → 导出案例研究文档 → 入库并供创作检索。全部整理指本次授权范围内成功获取的全部案例，列明失败项与覆盖范围，不承诺全平台穷尽。

案例保留作者、原链接、发布时间、采集时间、指标、内容版本及证据片段。普通资料更新禁止清除案例类别与未读线索限制；专用编辑携带版本并保留字段，研究任务按冻结版本导出，后续编辑和删除不改写历史报告。本人笔记仅在用户显式选择后导入表达参考，评论不自动进入该RAG路径。爆款筛选公开阈值、时间窗、可比样本和缺失项；无播放量不计算播放互动率。仅有标题/搜索摘要的视频标为线索，不能声明已读视频。商品事实、价格时效与案例表达分开存储。

## 4. 混合 RAG 与四角色

保留现有 BM25、原文版本和任务证据快照，计划加入向量检索、混合排序与重排；向量模型、预算与写作模型独立配置。通过固定检索样本比较召回与证据正确性，不能仅因使用向量库就宣称质量提升。RAG 是检索增强，不是训练模型。

受众洞察区分真实评论、模拟反馈及推测；研究核对商品事实与案例来源；创作参考开头、节奏、叙事和卖点组织，生成新的表达，不移植他人经历或商品功效；审核检查引用、事实、近似复制、虚构体验及功效承诺。四角色共享冻结快照，网页外部文本始终是数据，不能成为 Agent 指令。资料删除停止新检索，历史任务保留审计。

## 5. 平台 DeepSeek 与用户自带模型

基础真实 AI 默认使用平台服务端配置的 DeepSeek；免费模拟继续明确标注。用户可选择自带密钥（BYOK），输入厂商、模型 ID、API Key 和连接 URL，并进行连接测试。候选覆盖 DeepSeek、千问、Kimi、豆包、OpenAI（包括可调用的 Codex 系列模型）、智谱、MiniMax、文心、混元、Claude、Gemini 及自定义兼容端点。候选列入目录不等于已通过实际调用验证，模型 ID 与能力实施时复核。

所有调用仍经过 model_router.Calls，记录 provider/model/route/prompt/input/snapshot/sources/usage。用户密钥服务端加密、按 owner 隔离、界面脱敏、支持撤销；不回传明文。自定义 URL 防 SSRF、限制协议/地址/重定向；平台密钥不发送给任意自定义主机。BYOK 失败不静默回退到平台付费密钥。用户自付与平台额度分开；搜索、转写、向量化费用独立计算。

真实收费模型或第三方付费服务测试须有明确预算；此次开发授权不等于无限费用授权。后续已明确授权$0.05完成一次真实模型闭环，实际8次调用、15378 tokens、保守账本$0.0184536，停在人工确认；该预算不自动授权继续收费或其他厂商实测。模型切换冻结到任务快照，旧任务审计不改写；结构化输出、超时、错误、未知用量及取消规则继续执行。
