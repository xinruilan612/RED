## 1. 目标、范围与优先级

唯一主流程：**输入主题或产品资料 → 可选联网搜索 → RAG 资料库 → 四 Agent 创作 → 对话改稿 → 发布或导出 → 评论反馈改进下一篇**。

主平台是小红书；沿用现有项目、四角色及运行框架。旧抖音兼容、内容试飞台、风洞保留历史代码与资料，不扩张为本轮主流程或必经步骤。参考工具按需借鉴，不全部安装；不新增平台、客户端、管理后台或技能市场。

**当前授权与优先级**：2026-10-11 用户要求先统一 AI 参考资料，再继续必要的产品实现与验证，替代旧阶段“只改说明/不进入第三阶段”的限制。以已实现能力为底座，只补差距；不修改全局规则或创建 override，不发布互动。旧预算不是新收费授权，真实模型调用仍需独立有效预算。本轮不做图片理解/生成、视频下载/生成/转写、预测、额外平台或管理后台。

## 3. 数据、RAG 与评论边界

已取得正文、仅搜索摘要、视频文字描述、字幕/转写须分别标记。摘要不是已读正文；文字描述不是已看视频或音轨转写。搜索失败、无结果、正文不可访问、高互动指标未知分别记录。没有可比较真实互动时不能称为高互动案例；公开阈值、时间窗和覆盖范围，不计算缺分母的互动率。既有100赞或50收藏、最多核对6篇/保存3篇仅是当前代码策略，后续需在界面显示并按授权范围验证，不是所有主题的通用有效性保证。

商品事实、用户提供的亲历与表达案例分开标记；案例不证明用户产品功效。保留 BM25 和既有向量/混合检索代码，质量以固定样本及真实引用验收，不因采用向量库而宣称效果提升。资料停用只停止新检索，历史快照保留审计。

评论采集、评论归纳和写作采用是不同步骤。移除原始评论展示不连带删表删数据；后台仅向任务传递用户选定公开笔记的必要、脱敏证据及问题归纳。不参考评论时不得隐式注入；无评论时提示当前样本为空，不生成假评论、不认为平台没有评论。已有本人笔记导入表达参考不等于评论复盘已接通。

## 4. 能力选择、错误恢复与费用

联网、评论和附加能力选择应冻结进任务快照。关闭联网仍可用已授权本地资料；来源不可用可切换来源、粘贴有权使用的资料或跳过搜索。登录过期可在产品内重新连接；解析失败可换文件或粘贴文本；模型失败可测试/切换配置；关键产品事实缺失可补料或删除相应主张。返回修改导致下游证据/审核失效，保留旧版本，不能自动覆盖用户草稿。

模型连接保存不等于调用成功；测试连接会调用模型时明确费用并遵守独立预算授权。保留服务端加密、owner/account_id 隔离、URL 安全校验、平台密钥目的地主机限制、用量未知阻断与取消规则。历史小额测试预算不自动授权新调用。

## 5. 四角色与真实运行入口

角色卡见 [总览](../agents/00_overview_and_all_agents.md)，协议见 [统一执行协议](AGENT_PROTOCOL.md)。保留 audience/research/content/reviewer 四个角色 ID，不扩大工具权限。受众角色负责选题与问题，研究角色区分事实与表达参考，创作角色写作和对话改稿，审核角色核查并给出可操作的修正；不是四个彼此重复的写作器。

当前四角色运行提示词由 `backend/live.py::messages_for` 构造；`backend/runtime.py` 调用后经 `model_router.Calls` 发出，`backend/service.py` 保留兼容路径。Markdown 角色卡不是运行时自动加载源。`backend/operations_planner.py` 和 `backend/windtunnel.py` 是另外的计划/风洞提示词路径，不能当作四角色入口。b50c628 已包含 [原创创作](ORIGINAL_CREATION.md) 的方法/样例/事实三组证据，保持该边界，按当前需求补对话与评论上下文。实现与验收分别记录，不用文档更新冒充运行时完成。

## 5.1 模型、Skills 与用户选择的最小实现

模型页面只需要厂商、模型、API Key、连接地址、测试和启用；复杂协议/预算放高级设置。参考 CC Switch 的预设体验和 LiteLLM/one-api 的适配思路，复用现有网关，不部署另一套管理平台。默认 DeepSeek 密钥仅在后端；用户连接按用户隔离，失败不静默切换或泄露密钥。厂商有地域或协议差异时给明确指引；Codex 客户端/ChatGPT 订阅不是通用 API Key。不能保证任意密钥和上游永不报错，验收为可解释、可操作恢复、不丢输入和草稿。

Skills 是版本化的写作/研究方法与工具权限的组合；优先复用已批准的方法资料和现有工具。联网、自动案例参考、评论参考分别可选，选择进入冻结快照；不因关闭自动参考而禁用用户明确选择的产品资料，不暗装全部参考工具，不让外部文章或 Skill 文本执行命令或获取凭据。

## 6. 不冲突的工程约束继续有效

## 2026-10-10 第二轮具体修正：后台搜索与确认入库

本节保留 2026-10-10 的搜索交互要求；沿用主题研究、研究任务、账号隔离与连接器，不新增平台。阶段限制已由文首 2026-10-11 需求取代，不阻止本轮模型、文档输入和四角色协作实现。

- 搜索、详情读取和取消处理均在项目独立无界面连接器中执行，不操作日常浏览器，不以最小化替代无界面，不在失败后切换有界面或反复登录。已有登录文件直接复用；只有明确的登录失效才提示用户点击“登录 / 重新连接”，不因普通超时要求扫码。
- 正常流程唯一打开外站的入口是用户点击某条候选的“查看小红书原文”；一条链接新开一条对应笔记。保留来源返回的访问参数，不以去掉参数的裸ID链接冒充可访问地址。
- 当前页面保留关键词、选择与滚动；显示进度及取消。同账号同范围活跃任务复用，迟到响应不得覆盖新关键词。取消关闭对应在途请求并停止后续采集，不能影响其他项目或用户浏览器。小红书来源隐藏网页范围。
- 候选展示实际标题、图文/视频类型、真实封面（失败正常降级）、可展开正文、可得互动、发布时间/获取时间及原文链接。平台“万”等缩写保留原值，精确整数未知时保持null；不足互动证据仅标相关候选，不宣称爆款。视频仅展示已取得文字说明，不称已看视频或转写音轨；本轮不新增下载、生成或转写系统。
- 搜索候选可暂存恢复，但用户点击“加入知识库”前不得进入正式可检索资料库或创作上下文。点击原文不自动核实或导入；只导入勾选项；只有链接/摘要而无可用正文的候选不得伪装入库成功。
- 正式导入保存正文、来源、稳定笔记ID、内容类型、获取时间及版本，按用户/账号鉴权并按稳定笔记ID去重。重复或并发确认不重复入库，已有资料复用原版本，不覆盖用户修订。取消确认后只允许沿用原确认范围恢复，已保存项跳过。
- “搜索到多少候选”与“已加入多少资料”分开；无导入时不用“已加入0篇”代替搜索状态。逐篇暂存成功候选，后篇失败、超时和取消不清空成功结果；错误区分连接、登录、超时、访问限制、结构和解析。

验收固定查询“衬衣领子发黄”：无自动可见窗口、本地真实候选、确认前知识库不变、手动单条原文、返回选择保留、只导入所选且可重复恢复、刷新后可检索。登录失效/失败/部分失败/取消各记实测或替身边界，不能用伪造结果替代平台实测；不绕过登录、验证码或访问限制。

数据库补充：修复前核验 API 与 Worker 的真实数据库、schema、配置来源以及候选/正式资料存储；现已确认 8775 两者使用同一 PostgreSQL。没有证据时不得把搜索失败归因于 SQLite，不做无关迁移或清空。站内排序只覆盖本次平台返回集合，可得精确计数参与排序；未知或缩写计数不可伪造。


## 2026-10-10 通用跨主题搜索验收补充

完成标准：不同主题使用同一流程，输入主题→搜索→本地预览→主动打开原文→勾选确认→仅所选资料入库→检索。不得为验收词添加专用分支、固定笔记或预设结果；不做整仓重构、迁移或清空数据库。

逐阶段保留原始输入、规范化实际查询、来源/筛选、任务范围、搜索响应数量、可解析数量、排除原因、详情成功/失败和候选数量。去重覆盖 owner、账号、主题、来源、范围、筛选与确认模式；只复用同范围活动任务，不使用旧搜索结果缓存证明联网成功。

区分真正收到空数组、返回记录全不可解析、详情全失败、部分成功、请求失败、明确登录/访问错误。MCP HTTP 500 不直接等同平台上游 HTTP 500；没有成功响应时数量不可解释为“平台没有内容”。候选未确认不得进入正式检索。

正常研究的排队等待有截止，执行总时限180秒，每次连接器读取绝对时限65秒；仅搜索瞬时连接/超时/500最多重试一次，间隔3秒并检查取消。登录失效、验证限制、结构错误不自动重试。结束或取消清理请求，不自动弹窗、换词或无限重新登录。页面刷新任务状态失败有明确提示和最多两次恢复轮询；新旧主题分开、迟到响应不能覆盖新输入。

真实验收按顺序使用“衬衣领子发黄”“口红色号秋冬”和未参与调试的不同领域主题；同代码版本逐个请求，不用缓存，不并发刷平台。每次记录实际查询、缓存、最终状态、候选数及失败证据；至少一次新的非空联网结果必须完成确认入库和检索。替身测试、历史证据与本轮联网结果分别记录在现有进度文档。
