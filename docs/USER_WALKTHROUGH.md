# 有迹操作教程：从产品资料到发布前成品

这次只走一条主线：选账号 → 存产品资料 → 生成稿件 → 检查和修改 → 确认 → 下载成品。本教程只使用这条主线。

本机页面：[打开有迹](http://127.0.0.1:8766/)。这个地址需要本机服务运行；换一台电脑不能直接访问。启动方式见[部署指南](DEPLOYMENT.md)。

## 1. 先选对账号

在页面顶部“当前运营账号”中，选择本次要用的账号。点击“管理档案”，核对平台、目标受众和表达风格，修改后点“保存档案”。

首次试用不必把全部档案写得很完整。先让系统知道写给谁、希望对方看完做什么。例如：写给刚开始独立生活、想整理小空间的人；希望他们能判断某款收纳用品是否适合自己，并愿意查看产品详情。

这里保存的是你的创作档案，不等于已经连接小红书或抖音。账号名称相同，也不代表平台账号已授权。

## 2. 把可重复使用的资料存进资料库

点左侧“资料库”。它的作用是：产品介绍存一次，下次创作能继续选用，并且能回头看到稿件依据了哪份资料。

只有一次会用到的临时素材，也可以直接粘贴在创作页的“真实素材”，不必先入库。

以公开产品资料测试为例，可以选择宜家 KALLAX 收纳用品的一款具体商品。先打开该型号的官方介绍，再复制你实际读到、允许使用的文字。不同尺寸和型号不要混在一起；本教程不提供未经核对的价格、尺寸、承重或使用效果。

在“添加或更新资料”中：

1. 保存方式选“新增资料”。
2. 资料标题写“某款收纳用品｜官方产品介绍｜查阅日期”。
3. 在“或粘贴正文”中写入产品原文、来源链接和查阅日期。也可以上传 TXT、Markdown、文本型 PDF 或 Word 文档。
4. 点击“保存资料”。保存和文件解析不调用 AI。
5. 在“已保存资料”里点“查看原文”，确认内容完整、型号正确。
6. 在“试着检索资料”中输入原文里出现的产品名或关键词，点“查找原文”，检查是否找到相关段落。

建议资料包含：产品是什么、官方明确说明的特点、适用条件、使用限制。品牌方未提供的效果和用户体验不要代填。只保存官网简介，不意味着你亲自使用过这个产品。

上传文件单份最多 3 MB；PDF 最多 50 页。扫描件暂不支持 OCR，可改为粘贴可复制的文字。选择了文件时，以文件内容为准。

## 3. 让这份资料真正进入创作

在刚保存的那份资料旁，点击“用这份资料创作”。系统会进入创作页并选中这份资料。

展开“从资料库选素材 / 添加文件（可选）”，确认：

- “本次使用的资料”中选中了正确资料，最多可选 3 份。
- “检索所选资料的原文片段，保留出处”已勾选。
- 页面顶部仍是刚才的运营账号。

资料入库本身不会自动用于所有稿件；这一步才是告诉系统“这次要用它”。系统按本次需求检索相关片段，而不是把所有文件全文一起发送给模型。可以在任务的过程和素材记录中回看来源。

接着填写创作需求。示例可以直接改成你的实际产品：

- 主题：公开产品资料测试：这款收纳用品适合怎样的小空间，购买前要核对什么？
- 写给谁：刚开始独立生活、希望整理小空间的人。
- 表达风格：自然、具体、容易理解；不夸大，不假装亲测。
- 真实素材：本次是公开商品资料测试，不代表品牌客户。请把已提供的产品特点解释为读者关心的选购理由；资料没有说明的价格、尺寸或效果不要编造。最后给一个自然的进一步了解引导。

资料越准确，稿件越有依据。主题里写出产品名和关键用途，有助于检索到合适的原文。

## 4. 选择真实 AI，开始生成

“运行方式”选择“真实 AI · DeepSeek”。如果选的是“模拟流程”，得到的是免费流程演示，不是真实模型生成。

点一次“生成稿件并审核”，系统保存后自动完成分析、写作和审核，直到需要你处理。不再弹出费用确认。真实 AI 仍会产生费用，受预算上限约束；等待结果，不必逐步点击。

执行中会生成受众分析、素材分析、写作及审核结果。查看页面中的当前状态、真实模型调用次数和费用记录。等待时不要重复创建相同任务；已有任务可以从左侧“最近的创作”重新打开。

没有历史数据时，如果页面询问是否允许假设，你可以允许“明确标注的假设”继续测试。它只是写作方向假设，不能当成真实用户反馈。

## 5. 先看稿件，再决定怎么修改

拿到稿件后，先看标题和正文，重点检查三件事：读者是否看得懂产品用途；事实是否来自你提供的资料；是否出现了没有依据的亲测、效果或价格描述。

“讲清楚了”和“事实有依据”是两件事。语言自然不代表事实已核实；有来源也不代表表达一定好读。

如果需要自己改：点击“我来修改文案”，修改标题、正文、互动引导或标签，然后点“保存为新版本（不调用 AI）”。保存后可用“与上一版并排比较”查看修改内容。

如果需要 AI 修改：在“这一次想怎么改？”填写要求，点击“让 AI 按意见改稿并复审”，等待下一版和审核结果。检查实际修改是否满足要求；“上一版问题”描述旧稿，当前字数看本版计数。真实 AI 修改与复审会产生模型调用；达到次数上限后不能无限重试。

修改后有两条完成路径：

- 审核完成且当前版本允许确认：点“确认第 N 版”（N 为当前版本号）。
- 你已核对内容、理解现有审核问题并愿意使用：点“知晓问题，人工采用第 N 版”。这是人工采用，会明确记录，不会被写成 AI 审核通过。

如果页面显示“稿件已确认，无需再次确认”，这一环节已经完成，直接下载即可。“此前审核记录”保留供回看，不代表还有待办，也不意味着记录中的问题已经通过 AI 复审。

## 6. 下载发布前素材

在稿件和改稿区域下方找到“图卡预览与下载”。选择风格，点击“预览图卡”，逐页检查文字、排版和图片；更改样式后重新预览。之后点击唯一的“下载全部成品包”。

图卡使用模板排版，可用产品图各用一次，图片用完后只排文案；没有产品图时不能称为实拍成品。视频没有自动配音。预览与导出不新增模型调用。

解压后检查：

- images 文件夹：封面和正文图片。
- video 文件夹：无声图文视频，每页约 8 秒，总时长不超过 120 秒。如果视频不可用，里面会有“未生成说明.txt”；有说明不能算视频已做好。
- storyboard 文件夹：分镜与字幕。时长是编辑建议，没有经过配音时长测量；重新剪辑或配音后要对齐字幕。
- caption.txt：可复制到平台的发布文案。
- 使用说明.txt：成品的使用方法。
- execution-evidence.json、manifest.json：版本和执行记录，一般使用时不必阅读。

解压后预览图片、视频与文案，再决定是否发布。包内不包含网站操作演示录像；操作演示和要发布的内容成品是不同文件。


## 7. 到这里就是发布前完成

发布前完成的标准是：稿件已确认，来源能够回查，需要的图片或视频已下载并预览，平台、标题、正文和媒体版本都正确。

这时可以打开小红书或抖音，手动上传素材，预览后自行决定是否发布。有迹不会因为稿件确认或下载就自动把内容发到平台。

如需记录，到“作品与复盘”，在平台实际发布之后，填写作品链接和发布时间。没有真正发布时先不要填；“模拟发布”只用于演练，不会产生真实帖子。

## 遇到卡住时怎么办

### 网页读取失败或超时

在公开来源搜索页粘贴链接后，如果“读取正文并保存”失败，点“去资料库粘贴原文”。自行打开官方来源，复制可使用的原文，同时注明链接和日期，再点“保存资料”，然后“用这份资料创作”。不要把搜索摘要当作已读正文。已有资料仍可继续使用，不必等待搜索恢复。

### 页面一直显示正在执行

先查看状态和错误提示，再刷新页面或从左侧重新打开原任务。服务与 Worker 正常运行时，后台任务不依赖当前页面持续打开。不要反复点开始或创建新任务来代替等待。

如果提示调用用量未知，系统会阻止自动重发，避免重复收费。保留原任务，先核对调用状态；不要把报错当成没有产生调用。

### 模型返回内容无法读取

系统会说明失败阶段，保留已完成的分析。完整JSON外包了一层代码围栏时，会在本地识别，不额外调用模型。若内容仍无法解析但用量已确认，可按页面的“重试并继续到审核”继续，仍受原来的调用次数和费用限制；已完成步骤不会重跑；再次失败会停止，不会自动反复重试。若显示用量未知，系统会阻止重复请求，需要先核对接口记录。历史请求未保存的原始响应与用量不能事后补造。

### 审核结果无法读取

查看页面说明，已有稿件会保留。可用时点击“重试并继续到审核”；若提示用量未知，先核对记录，不要重复请求。手动修改可展开“其他处理方式：手动修改”，之后是否复审以页面显示的可用次数为准。

### 资料很多，生成稿却没用上

回看这次是否启用了资料检索、是否选中正确文件、是否仍在正确账号。用资料库的“查找原文”测试产品名和主题关键词；若相关信息太散，可以补充一份有来源、型号明确的产品资料摘录，再开始新任务。不能只因为文件已上传，就认定模型已经使用了整份文件。

### 已确认，但仍能看到旧审核意见

看页面顶部的完成状态。已确认的版本可下载；展开旧记录只是回看依据和限制，不需要重复确认。若你发现事实仍有问题，应修改后再确认新版本，重新导出对应素材。

## 第一次只需记住这条路线

资料库保存原文 → 用这份资料创作 → 真实 AI → 阅读和修改 → 确认当前稿件 → 下载并预览。先做出一篇你愿意使用、有资料依据的内容，再考虑试读和发布后的复盘。
