# 公开搜索与失败恢复验收（2026-10-04）

公开搜索提供选题及事实线索，不提供小红书 / 抖音平台热榜、账号授权、评论全量数据或爆款预测。搜索和读正文由用户主动发起，摘要不能冒充已读正文。模型调用与网页检索分别记录。

## 可运行路径

- 免费 Bing 中文 RSS 检索保留为实验渠道。连接失败时最多尝试一次同供应商备用入口，不无限重试；无相关结果时建议换简短关键词。
- 维基百科官方公开 API 用于背景资料，读取正文后可保存到账号资料库，不代表最新新闻或平台热度。
- Brave Search API 为可选正规网页搜索入口，用户需自行启用订阅并在**服务进程环境**设置 `BRAVE_SEARCH_API_KEY`。这不是 DeepSeek 密钥；默认免费搜索不调用 Brave，Brave 请求不自动重试，也没有本项目搜索费用台账。
- 受保护网页读取失败时，用户可打开原网页核对、在资料库手工粘贴有权使用的原文或上传文档，使用已有资料继续创作。

供应商边界依据：[Brave API 身份认证](https://api-dashboard.search.brave.com/documentation/guides/authentication)、[Brave 搜索 API](https://brave.com/search/api/)。2026-10-04 核查需要独立密钥与订阅；免费额度、付费和注册要求以供应商当前订阅页面为准，本轮未启用订阅、未调用 Brave。

## 失败与缓存

单次搜索总上限 20 秒，单篇正文上限 15 秒，任务联网调查总上限 35 秒。系统 DNS 及固定供应商连接有调用方等待上限。超过时限的来源不作为证据；已取得的相关正文仍保留，失败列表与下一步提示分别展示。

搜索缓存 5 分钟、公开正文缓存 30 分钟，最多 128 个进程内条目；服务重启失效。缓存保留首次检索 / 读取时间，不能重新标成最新内容。保存到资料库及创作任务的证据快照继续按原有持久化机制保留。缓存不含账号档案、密钥或上传文件。

本机沙箱网络拒绝访问，以下使用授权公网探测，不使用收费模型或模拟响应。

| Bing `护肤 保湿 防晒` | 约 0.6 秒，8 条相关摘要，包括百度百科护肤、护肤顺序文章、知乎新手护肤 |
