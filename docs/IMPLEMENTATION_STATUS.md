## 已能使用

- 填写创作需求、目标读者、风格和素材，创建任务。
- 同时执行受众/素材模拟分析；逐步查看策略、提纲、开头、标题、正文。
- 查看每个角色的输入、输出、实际阶段耗时和运行记录。
- 在资料不足时可视化补料；审核发现问题时选择自动返修或手动编辑。
- 改稿保存新版本、比较旧稿与新稿、再次审核、人工确认准确版本。
- 下载确认后的 Markdown；同一浏览器刷新保留历史。
- 后端提供状态校验、持久化、版本冲突拒绝、命令幂等、会话隔离、CSRF/Origin/Host 检查；预算基础规则仍由原领域层测试验证。

## 上一阶段边界（新增真实模型适配后以本文首段为准）

真正调用模型写文章、联网检索、分析真实历史指标、图片生成与图文包导出、正式账号登录或云端多人使用。四 Agent 当前采用固定模板，模拟审核不能当作真实质量保证。

## 技术边界

新增 backend/demo.py（四角色模拟及逐阶段执行）、backend/web.py（仅回环 HTTP 适配）和 frontend/（原生页面）。这是零第三方依赖的可替换演示适配层，不改变后续 FastAPI/Next.js/PostgreSQL/队列的产品部署计划。创建的 Run 增加 context/artifacts/node_runs/reviews，旧本地域记录仍可由默认字段读取；网页仅创建和操作模拟任务。

模拟 reviewed 守卫由服务端固定模拟规则产生，浏览器不能提交任意 gates、branch 或 reviewed。未接语义事实核验和规则包有效性服务。单次请求在事务内执行，服务重启可恢复已提交结果，不意味着实现了后台 Worker 租约恢复。完整角色产物 Schema、Tool/Skill 运行资产与长期 Memory 接口仍待后续阶段。

## DeepSeek 接入增补

新增 provider.py（安全配置/HTTP）、live.py（角色输入输出与素材适配）、execution.py（事务外调用、步骤幂等、用量记录）。网页支持 live/simulation；填写 Key 不会自动产生调用。默认依旧禁用收费模型，选择真实模式并执行后才启用。

验证：63 项自动测试通过，其中包含9项真实本机 HTTP 测试；所有模型响应均为测试替身，没有使用真实 API Key。覆盖正常链路、人工改稿复审、模型返修、补料、重复请求、取消晚到响应、费用限制、未知用量与错误脱敏。真实生成质量、延迟和实际账单尚未验证。

## 用户节省额度要求增补

2026-09-20：同一步累计最多3次（含首次），初稿+自动返修共最多3轮；第3轮仍未通过即失败。接口错误/超时/格式错误继续采用一次失败就停止，不自动重试。计数持久化，补料和手动编辑不重置，仍受整单16次、40000 Token与费用估算预算约束。

66项自动测试通过；额外验证了3轮不通过终止、手动改稿不能绕过审核次数上限、提纲校验失败后不再调用。真实测试共4次调用/7956 Token，失败详情见 [DeepSeek 记录](DEEPSEEK_SETUP.md)。

## 运营 Demo 功能实现

用户明确授权增加 Demo 功能后，已在已有目录实现五页运营工作台，没有新建目录或另起项目。

- 热点与选题：四条固定示例、用户来源导入、观察时间、超过三小时提示重查、平台/关键词筛选。选题冻结进入创作上下文。没有联网、实时热榜、自动评分。
- 创作：保留四 Agent 与版本复审；增加账号/目标平台；抖音输出口播与分镜脚本并标记非成片。默认免费模拟，不因配置 Key 自动选中真实 AI。
- 发布：只接收已确认准确版本；再次确认账号与稿件，支持 SIMULATED 演练及真实 AI 稿人工链接回填 MANUAL_REPORTED；不同状态不可混淆，国内官方接口未接通。
- 指标：按帖子和目标观察窗口录入当前快照，未知为 null；修正保留旧记录并使旧经验失效。UI 只展示同帖同窗口最新快照，不重复累加。
- 经验：确定性计算互动次数/阅读或播放比；一篇只作描述性复盘和下次实验建议。用户接受后同账号、同平台、同模式复用，支持拒绝/撤销。不是在线训练，不证明传播效果改善。

backend/operations.py 将运营记录放入已有 SQLite 的独立表；读写按会话隔离、事务提交、版本冲突拒绝和幂等重放。frontend/operations.js 实现五页切换，原创作流程仍由 app.js 管理。新接口和对象是本机演示适配，不冒充完整 v0.4 生产契约；LangGraph、队列、OAuth、自动发布/回流仍待实施。

本轮完整流程、测试与备份见 [网页验证记录](WEB_DEMO_VALIDATION.md)。

## v0.5 长期账号运营：账号基础（2026-09-20）

用户确认按四阶段推进。账号基础新增稳定 account_id、版本化定位档案、独立历史作品导入、同类账号观察、用户改稿差异与本地空间恢复码 API。旧运营 JSON 在读取时兼容迁移，首次写入持久化；不更改旧稿件或发布状态。用户编辑与偏好记录同事务，仍须复审；恢复码仅保存哈希，重新生成使旧码失效。

阶段验证：86 项单元/本机 HTTP 集成测试通过，新增身份隔离、改名保留历史、旧数据兼容、编辑幂等和恢复码换浏览器用例；未调用收费模型。此阶段尚未交付账号 UI，后续阶段继续接入。修改前源码和数据库备份位于已有 runtime/before-account-operations-*，不含 .env。

## v0.5 四角色与分析、计划连接（2026-09-21）

四角色读入账号档案、历史、编辑偏好、人工竞品观察与已接受经验；新增结构化选题卡/创作简报/标题比较理由，标题另选仍创建新版本并复审。新增独立 AnalyticsAgent 确定性规则执行器与周计划服务：按同口径历史比较，输出观察/假设/实验，缺失保留未知；人工采纳、修正失效、撤销传播到后续计划。

后端测试增至94项通过，覆盖历史基线、早晚窗口、未来数据排除、来源/账号隔离、基线修正失效、计划撤销、元数据校正、视频指标守卫与账号上下文。四角色模型测试为离线替身，本轮没有真实 DeepSeek 质量测试或费用。浏览器 UI 验证和最终完整检查见 WEB_DEMO_VALIDATION.md 后续记录。

最终交付补充：全量96项测试、三份前端脚本语法检查与空白检查通过。浏览器完成演示分析→经验→周计划→账号上下文创作→候选切换/手动编辑→复审确认→偏好记录，服务重启后历史保留。新版入口为 /#overview；详情见 [验证记录](WEB_DEMO_VALIDATION.md)。规则分析与模拟流程不作为真实账号增长或真实模型质量证据。

## v0.6 第一阶段：网站后端、用户与数据库（2026-09-21）

新增 FastAPI 适配 api.py、应用边界 service.py、Auth 密码账户与可撤销会话、database.py 双数据库边界和 migrate.py 快照迁移。密码使用 PBKDF2-SHA256 600000 次加盐；会话与恢复码只存哈希，注册/登录轮换会话，重设密码撤销全部旧会话。写操作要求同源和 CSRF，认证节流持久化。公网配置要求 HTTPS 与内测邀请码，但这不等于已经完成公网部署。

PostgreSQL 保留原创作与运营 JSON 聚合，新增有账号外键的 social_accounts/account_records 索引目录，与聚合写入同一事务；并非所有业务字段都已拆成独立列。短写事务先用全库事务咨询锁串行化，适用于初期内测，尚未做高并发性能评测。网站用户与社媒账号区分，社媒平台 OAuth 尚未接通。

已将 runtime/before-web-foundation-hotspot-review-demo.sqlite 的 5 个任务、48 个命令、1 个运营空间、14 个运营命令、2 个旧会话复制到独立 youji_operations 数据库，逐行相等；原文件保留。注册时需持有原浏览器 Cookie 并显式选择绑定旧空间，同一空间只能认领一次。旧的本地恢复 API 不在网站适配中开放。

资料库/真实搜索在下一阶段实施；持久后台执行、平台发布与指标 API、云部署仍未完成。测试和交付证据见 WEB_DEMO_VALIDATION.md。
