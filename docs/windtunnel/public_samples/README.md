# 公开教程候选样本

这批资料用于“Python 3.12 初学实用教程”的内容检查试验选样：10 个不同主题，来自 Python 官方英文文档。S01–S03 为探索样本，S04–S10 为候选留出样本。选样者已读取全部资料，尚未冻结，也不是严格隐藏留出；不得把这批资料宣称为已完成评测。

每个样本有 `support.md`（所选官方章节全文）与 `draft.md`（公开教程章节原文节选候选输入）。两者有意使用同一公开章节，用来验证清晰度、结构与证据约束，不能直接等同“来自真实博主的待修改稿”；正式实验还需确定独立的评分题、任务边界与足够的资料覆盖。官方教程本身已经过编辑，这批输入可能存在天花板效应，不能代表普通创作者稿件分布。

草稿保留英文，不使用来源许可不明确的中文翻译。不人为插入错误，不生成单次模型基线或风洞最终稿。没有真实作者反馈、真人评分、传播效果、模型费用或实验胜负结果。

`LICENSE_PSF.txt`、`LICENSE_0BSD.txt` 保存对应完整许可章节；`LICENSE_SOURCE.txt` 保存官方 History and License 正文完整文本；`license.html` 保存原始页面。原始教程 HTML 保存于 `sources/`。每份材料均保留来源 URL、采集时间、许可及改编说明；改编仅删除网页锚点符号、整理空白、增加说明，原英文教学内容不改写。

`manifest.json` 记录 HTML、抽取章节、support 与 draft 的 SHA-256。采集时间使用 UTC，不能把采集时间当原文发布时间。`/3.12/` 是会继续更新的版本系列网址，实际内容以存档和哈希为准；不声称引用内容永远对应某固定补丁版本。

原始 HTML 按下载字节保留，包含官网自身的行尾空白；`.gitattributes` 仅对这些原始网页关闭空白诊断，避免为排版检查修改证据。其他源码与文档仍执行正常空白检查。

## 复核与重采集

`python3 docs/windtunnel/public_samples/collect.py` 从官方网站重新采集并重写本目录的样本与清单；网络访问需要运行环境允许。重采集会改变时间或来源哈希，应在实验冻结前完成，冻结后不得覆盖样本。脚本不读取密钥、不调用模型、不提交 Git、不联系作者。

实验使用前仍需独立确认适用性、章节完整性、难度和样本分组；后续如制作中文改编稿，必须新增清晰的改编记录与对应文件哈希，不伪称原作者中文作品。
