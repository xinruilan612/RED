JSON is a format for storing structured data. Python includes a json module for working with it.

If you want to save a structured value such as x = [1, 'simple', 'list'] and later restore it, one supported approach is to use JSON. The standard json module can take Python data hierarchies and convert them to string representations. This conversion process is called serializing. Reconstructing the data from the string representation is called deserializing.

To view the JSON string representation of x, use json.dumps. For example:

>>> import json
>>> x = [1, 'simple', 'list']
>>> json.dumps(x)
'[1, "simple", "list"]'

The variant dump() serializes the object to a text file. If f is a text file object opened for writing, use:

json.dump(x, f)

To decode the object again, if f is a binary file or text file object opened for reading, use:

x = json.load(f)

JSON files must be encoded in UTF-8. Use encoding="utf-8" when opening a JSON file as a text file for both reading and writing.

This simple serialization technique can handle lists and dictionaries, but serializing arbitrary class instances in JSON requires a bit of extra effort.

JSON should not casually be replaced with pickle for untrusted data. Contrary to JSON, pickle is a protocol which allows the serialization of arbitrarily complex Python objects. As such, it is specific to Python and cannot be used to communicate with applications written in other languages. It is also insecure by default: deserializing pickle data coming from an untrusted source can execute arbitrary code, if the data was crafted by a skilled attacker.
