List Comprehension Cheat Sheet

1. Filter out negatives and double the rest (vec = [-4, -2, 0, 2, 4]).
Expression:
[x*2 for x in vec if x >= 0]
Result:
[0, 4, 8]
Evidence: The manuscript shows [x for x in vec if x >= 0] gives [0, 2, 4], and [x*2 for x in vec] gives [-8, -4, 0, 4, 8]. Combining the filter and the doubling on vec = [-4, -2, 0, 2, 4] yields [0, 4, 8].

2. Flatten [[1, 2], [3, 4]] in order.
Expression:
[num for elem in [[1, 2], [3, 4]] for num in elem]
Result:
[1, 2, 3, 4]
Evidence: The manuscript gives the pattern [num for elem in vec for num in elem] with the listed flattening example vec = [[1,2,3], [4,5,6], [7,8,9]], which produces [1, 2, 3, 4, 5, 6, 7, 8, 9]. Applying the same pattern to [[1, 2], [3, 4]] gives [1, 2, 3, 4].

3. Making (number, square) pairs: the tuple expression must be parenthesized.
Expression:
[(x, x**2) for x in range(6)]
Result:
[(0, 0), (1, 1), (2, 4), (3, 9), (4, 16), (5, 25)]
Evidence: The manuscript states, "If the expression is a tuple (e.g. the (x, y) in the previous example), it must be parenthesized," and shows that [x, x**2 for x in range(6)] raises SyntaxError: did you forget parentheses around the comprehension target?

4. Two for clauses and one if clause correspond to nested for loops plus an if.
List comprehension:
[(x, y) for x in [1,2,3] for y in [3,1,4] if x != y]
Result:
[(1, 3), (1, 4), (2, 3), (2, 1), (2, 4), (3, 1), (3, 4)]
Equivalent ordinary loops (from the manuscript):
>>> combs = []
>>> for x in [1,2,3]:
...     for y in [3,1,4]:
...         if x != y:
...             combs.append((x, y))
...
>>> combs
[(1, 3), (1, 4), (2, 3), (2, 1), (2, 4), (3, 1), (3, 4)]
Evidence: The manuscript says, "Note how the order of the for and if statements is the same in both these snippets." The first for is the outer loop; the second for is the inner loop; the if filters the inner results.

5. Variable side effects: ordinary for-loop variable vs. list-comprehension variable.
Ordinary for loop:
>>> squares = []
>>> for x in range(10):
...     squares.append(x**2)
...
>>> squares
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
After this loop, x still exists. The manuscript says, "Note that this creates (or overwrites) a variable named x that still exists after the loop completes."
List comprehension example:
squares = [x**2 for x in range(10)]
The manuscript presents this as avoiding side effects: "We can calculate the list of squares without any side effects using" the list comprehension (or the equivalent map/lambda form). Thus the ordinary for loop leaves its loop variable in the surrounding namespace, while the list-comprehension example is described as side-effect-free for the variable it uses.
