Basic use

Importing the main class:

>>> from pathlib import Path

Representing the current directory:

>>> p = Path('.')

Listing subdirectories:

>>> p = Path('.')
>>> [x for x in p.iterdir() if x.is_dir()]
[PosixPath('.hg'), PosixPath('docs'), PosixPath('dist'),
 PosixPath('__pycache__'), PosixPath('build')]

Listing Python source files in this directory tree:

>>> list(p.glob('**/*.py'))
[PosixPath('test_pathlib.py'), PosixPath('setup.py'),
 PosixPath('pathlib.py'), PosixPath('docs/conf.py'),
 PosixPath('build/lib/pathlib.py')]

Navigating inside a directory tree:

>>> p = Path('/etc')
>>> q = p / 'init.d' / 'reboot'
>>> q
PosixPath('/etc/init.d/reboot')
>>> q.resolve()
PosixPath('/etc/rc.d/init.d/halt')

Note: The result of q.resolve() is an example from a specific machine and may differ on other systems.

Querying path properties:

>>> q.exists()
True
>>> q.is_dir()
False

The example shows q.exists() as True, meaning the path exists, and q.is_dir() as False, meaning the path is not a directory. These results are from the example machine and may differ on other systems.

Opening a file:

>>> with q.open() as f: f.readline()
...
'#!/bin/bash\n'

This reads the first line of the file at q.
