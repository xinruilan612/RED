# 本机真实流程交付与使用（2026-10-04）

## 现在怎么使用

本机已启动的网站为 http://127.0.0.1:8766/ 。Chrome 原有登录继续有效，原作品和复盘记录保留。

1. **作品与复盘 → 数据复盘**：先看实际阅读、收藏、点赞，再看“值得保留、下一篇改什么、怎么知道有没有用”。免费计算不调用模型。点击真实 AI 按钮并确认后，将正文、账号档案及人工指标发给已配置 DeepSeek，调用一次；同一记录刷新或重复提交不会重新收费。失败也不自动重发。
2. **创作 → 选题与来源**：免费公开网页搜索提供线索；百科提供背景资料。点击“读取正文并保存”，在资料库核对原文，再供创作使用。被网站限制或超时就换链接、粘贴有权使用的原文或上传文档。搜索20秒、正文15秒、创作联网调查35秒；成功部分保留，摘要不当作正文。
3. **已确认稿件 → 下载图文包 / 无声图文视频 / 分镜与字幕**：下载ZIP并解压。图卡为中文封面及完整正文，caption.txt为文案；视频为真实可播放MP4，分镜包含SRT。使用准确确认版本，不额外调用模型。长稿超过明确上限会拒绝，不截掉内容。
4. **稿件 → 用此版本做读者理解检查**：带入稿件与材料，填写作者问题或有权使用的真实读者问题，保存后主动启动；确认问题卡，再启动阅读和材料核查，最后结束并下载报告。真实 AI 检查不能替代真人意见。材料仅说明输入证据，不表示已独立核验来源权威性。
5. **更多工具 → 进阶：假设与试飞**：记录需求和想尝试的改进，选两份现有真实稿件。下载给真实读者分别看，逐人填入回答、是否看懂及是否愿意行动；系统汇总实际人数，不要求编造总数。AI检查可跳过。发布后回填两版真实作品链接和同口径指标，匹配准确稿件快照后比较；你确认后才作为探索性经验复用。只有一篇发布，仍可复盘，但还不能比较两版发布效果。

模型已配置时，普通新建创作、周计划及试飞创作默认选择真实 AI；示例入口保持明确模拟。选择模式不自动调用，按开始后才计费。账号切换、旧任务、旧报告仍保留隔离和审计。

## 问题卡为空时怎么继续

如果“确认问题卡”显示0条或“检查条件需要1至12项”，可直接在下面填写“希望读者看完后能回答什么”以及适用读者，点击“保存我的问题（不调用AI）”。原稿保留，问题明确标为作者设定；确认后再启动正文检查。此入口不会重新收费生成问题卡，也不会覆盖已有条件或绕过未核对的付费用量。
