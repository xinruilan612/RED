# 开源图卡模板与人工验收

本轮目标：用户确认的文案 → 选择模板 → 真实产品图片与正文排版 → 预览 → 下载同一套成品。排版不调用写稿模型、不改写已确认内容。

## 开源来源

- 主要视觉模板：[bozhouDev/xhs-article-to-images](https://github.com/bozhouDev/xhs-article-to-images)，MIT，固定提交 `79d2ccce32ff44236bf504a39b850637acacd950`。接入雅刊、暖杏奶咖、雾松青、黛墨描金、夜读鎏金、粉色王国、乙游夜境、自然手记八套主题。保留上游许可，示例作者头像、品牌和二维码不进入用户成品。
- 分页参考：[haodongcui/md2card](https://github.com/haodongcui/md2card)，MIT，固定提交 `f672126c5caba634244c34aebcd5c83e11f0cc52`。参考真实高度测量、段落保护、过长内容续页的设计；不是整站搬迁，也不宣称本项目原创了其排版方法。

模板目录与稿件模板选择持久化到数据库；渲染采用固定版本的本地模板文件，不执行数据库中任意 HTML 或脚本。读页面和刷新不推进轮换；点击换一套才改变已有稿件的模板。图片版权与模板代码许可分别记录。

## 人工验收步骤

1. 打开已经确认的罗技稿件，找到稿件下方的“图卡预览与下载”。无需重新生成文案。
2. 选择“雅刊”，检查封面和全部正文页；再选“雾松青”或“夜读鎏金”，观察版式、背景和字体层级的区别。
3. 点击“换一套”，应显示下一种模板。刷新网页，应保留这篇稿件的选择。
4. 不上传图片，罗技 M185 应仍显示已匹配的多角度实拍图；每页优先使用不同图片，图片用完后的页面只排正文。其他未匹配产品需要补充图片。
5. 模板列表始终展开；不提供字号和强调色设置，统一使用标准字号与模板原色。历史自定义配色不会再影响新预览或下载。
6. 点击“下载全部成品包”；若设置刚变化，系统先按新设置排版再打包，不下载旧预览。
7. 解压后依次打开 images 中的所有图片，和网页预览核对：模板、页序、图片、正文一致；文字没有裁切、漏字和重复。caption.txt 应仍是你确认的原稿。

如果排版失败，应显示明确原因；不要将没有图片的包当作图卡已生成。下载不表示内容已发布，人工采用也不等于 AI 审核通过。

## 验证记录

完整后端回归：948 项通过，0 跳过，包含 PostgreSQL 集成测试。前端回归：286 项通过。另对最终渲染器执行 7 项专项验证，全部通过，包括八套主题、全部正文和标签保留、无孤立标签页、不同产品照片、整套改色及预览导出像素一致性。

本地 Chrome 实际验证：选择夜读鎏金 → 换一套 → 暖杏奶咖 → 刷新保留暖杏奶咖 → 直接点击下载，由页面自动预览并下载 ZIP。实际包包含 PNG、无声 MP4、文案、分镜和来源/许可文件。本轮没有调用收费模型。

八套实际确认稿样图位于本地 `output/mit-card-templates-20261009/`，未将用户运行数据提交 Git。其他系统的浏览器安装和公网部署未在本轮验收。
