# 公开笔记参考库与选题比较

入口：更多工具 → 选题潜力 → 公开参考。

## 使用流程

1. 点击“扫码连接小红书”，用手机小红书扫码；再点“检查搜索连接”。连接器使用独立登录，不读取Chrome已有Cookie。
2. 输入具体领域关键词，点击“搜索公开参考”。每次混合综合、最新、最多点赞三种排序，每组最多8条；去重后保存当前账号参考库。搜索结果有平台排序偏差，不代表随机或全量样本。
3. 搜索初始内容标为摘要；需要全文时点击“读取正文 / 更新互动”。保留最近30次观察快照，记录真实采集时间；每账号最多保存200条，最近100条参与比较。
4. 写入候选标题、正文，可上传自己的候选封面，再点“比较这些选题”。真实Chinese-CLIP将候选、定位和公开文本编码并选取相关参考；公开封面未下载编码时明确标注，不声称看过封面。
5. 结果分别列出自有历史与公开参考，公开参考可打开原笔记，显示来源、采集时间和当时互动数。可以下载比较报告，或将候选带入原创作流程。
6. 暂时无法连接时，展开手工添加参考，填写真实笔记链接、标题和正文。未知计数留空，0表示明确观测到零；手工来源有独立标记。

## 指标含义

公开点赞/收藏/评论是采集时累计计数，不是你的未来结果；不会进入自有账号的训练标签、发布记录、经验或个人热度估计。自有历史预测门槛保持不变。

当前实现的是联网样本采集和个性化图文参考筛选，还不是经过小红书前瞻验证的跨账号热度预测器。后续需要足够同观察时长、相近账号体量的真实样本及持续快照，按时间切分训练、验证、测试并优于基线，才能输出有证据的未来互动估计。不能因为找到热门笔记就直接产生爆款概率。

## 本机连接器

上游：[xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp)，固定官方发行v2.5.5（Apache-2.0）。上游二进制保存在忽略的runtime/xhs目录，不作为自研算法或项目源代码提交。模型采用与现有选题模块相同的Chinese-CLIP。

连接器只绑定127.0.0.1:18060；随机Bearer凭据保存在runtime/xhs/auth-token，网站owner绑定保存在runtime/xhs/owner-id，目录权限700、配置600。登录Cookie在同一私有目录，不能提交、打印或打包。网站只开放搜索、详情和登录检查接口，不代理发布、点赞或评论。

只有配置的一个网站用户可使用本机登录连接；其他用户仍可手工导入其自己的公开参考。公网多用户服务不能共用此本机登录配置，需另做每用户连接管理。

官方API与页面结构可能变化，登录/网络失败显示温和提示。单次上游请求超时15秒，无隐式无限重试；已取得的部分排序样本保留。URL固定本机，禁代理和重定向；参考图片仅存URL，不执行任意URL下载。外部正文始终作为资料，不作为系统指令。

已安装的macOS ARM64官方v2.5.5二进制SHA256：`fad3633fda4a8060e66e2941bc8fc5460326c7cb4e58a32485a9e2c9408e95a8`。

已有本机配置下，原命令 `runtime/venv/bin/python scripts/local_dev.py start` 会启动或复用公开搜索连接器；只有本次启动的子进程会随网站退出。也可单独前台运行 `runtime/venv/bin/python scripts/local_public_search.py`。未配置或端口冲突不会阻断原网站。
