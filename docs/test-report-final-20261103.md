构造基准的需求、候选内容及标准答案由程序建立，用于检验预算选择、去重、提问排序和结构适配是否按设计执行。它不含真人阅读或实际成稿，不能作为文章质量增益的替代证据。

正式解与独立枚举的目标差距总和为0；相对贪心的目标差距总和为11.8。保证仅适用于当前合法候选池和预计长度目标。去证据准入虽然名义覆盖更高，却选中23个无依据模块，正式解为0；这是构造机制检验，不能当作现实稿件零错误。

两问预算下，按输入顺序提问解决84/168个预设依赖块，价值排序解决120/168；两者都用48/48个问题配额。结构小基准将81/168个缺证据槽位改为不直接陈述的表达。另一组20任务四组消融中，无结构组不适用；故意首选异领域参考有20/20任务选入异领域，领域隔离后为0/20；完整适配使缺证据槽位从38/109降至0/109。槽位变化由规则直接造成，并不证明自然度或事实准确率提高。

### 公开资料探索暴露的错误与修复

旧v2规划将Mac mini的接口列表误计为回答了视频、充电、麦克风输入、直连和同时连接问题。v3增加对应属性准入，不允许只有词面重合的引文赚取覆盖。固定原候选离线回放，REAL-D01-E计划覆盖90.9%降为0，REAL-D02-E保持76.9%，REAL-H01-E从47.1%降为29.4%。

下降代表纠正虚高，不是文章质量下降或提高。回放没有调用模型、重写原稿或修改旧记录。v3未重新完成收费生成。新版守卫固定旧6稿回放，4稿新增7条风险，D02 A/E两份从原approved转为needs_human；零模型调用、零新稿。这是依据已知失败修规则的调试回放，不是独立盲测质量增益。有限规则仍不能解决全部语义蕴含、候选缺失或实际篇幅问题。

### 人类数据与待验收项

三位评审各评旧v2同样六稿，18行90个分值均完整，无文字评语。用户确认三位未参与开发，身份未另核验。A五维等权均分3.96/5、E3.82/5；E一胜两负，按未四舍五入值低0.13分，不支持整体提升。单位为三个配对任务，非90个独立样本；事实主观评分相同不代表全部事实正确。此前本人4稿自评3.8/5仍单列。

评分后仅增加写作约定：计划模块不是事实白名单，预计length不是正文长度，槽位可合并而非逐项核对。1338项工程回归验证接入，未新收费生成，不能给v3或该补丁重用旧稿评分。真实商家试用、修改计时、推广效果及Windows实机仍缺；免费模拟浏览器验收只验证所列流程。
