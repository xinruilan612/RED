## 使用方法

1. 登录8775网站并选择自己的项目账号。在“账号数据连接”查看已绑定会话；过期时点击扫码重连并在本人手机完成登录。初次绑定仍由本机管理员核对网站用户、项目账号和平台身份，不自动认领公共浏览器会话。
2. 查看持久笔记与评论分页。选本人笔记导入表达参考，才会进入案例/RAG；导入需要明确确认用途，评论不进入这条导入链路。
3. “案例研究”选择搜索服务与范围。xhs_local只使用已绑定本机账号，读取有限视频文字描述及可见互动；未取得音轨/字幕时不声称已分析视频内容。网页搜索的小红书收录结果仍只作为线索，不等于官方搜索接口。
4. 点击“编辑案例”维护已有资料；正文按字符位置去重，来源链接、内容类型、用途、未知指标、规则及时间保留。保存携带document_id与expected_version，旧版本留存；并发变化需刷新处理。普通资料更新不能把未读线索变成普通正文。
5. 查看原文、下载研究文档，在创作工作台选择资料后运行四角色。商品宣传与表达案例不能直接证明用户产品功效或亲身体验；未知互动指标不能称为爆款。最终人工确认仍独立于AI审核及平台发布。

公开网页研究仍限最多2个关键词、6次页面读取、3份成功资料，同时每用户最多3个活动任务；报告保留失败、覆盖范围和来源。案例文档只覆盖本次取得的样本，不宣称全网穷尽。编辑或移除已入库案例后，本次研究报告仍按保存时的冻结版本回查。

本地真实BGE安装、固定revision/hash、缓存、256块上限与BM25回退见 [本地RAG指南](LOCAL_RAG.md)。平台密钥、Cookie、二维码数据和个人后台内容不提交Git，不进入模型或公开报告。
