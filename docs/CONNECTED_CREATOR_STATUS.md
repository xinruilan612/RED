搜索提供商为 Bing 实验搜索、维基百科背景检索和需自备密钥/显式费用确认的百度搜索。目标可选全网、京东、淘宝/天猫、小红书公开搜索线索；限定站点搜索不等于平台官方接口或完整站内搜索。品牌官网可通过全网查询和有权公开 URL 导入研究。

研究任务首版限制为最多 2 个关键词、6 次页面读取、3 份成功资料，同时每用户最多 3 个活动任务。报告保留成功/失败/中断与覆盖范围。只有已读取且权限允许保存的正文参与案例检索；搜索摘要不是已读视频或正文，未知互动指标不能称为爆款。

## 使用流程

1. 登录网站并选择自己的项目账号，在“模型与搜索”使用平台 DeepSeek 或保存自己的模型连接。保存密钥不触发测试；点击测试可能计费，须确认预算。不要在聊天、资料或提示词中填写密钥。
2. 在“案例研究”选择来源、查询和资料用途，确认有权保存后启动研究。后台完成后查看成功与失败项，下载研究报告；也可手工导入有权使用的正文/字幕或未读线索。
3. 在资料库查看检索引擎说明，创建任务时选择资料。表达参考用于内容结构与表达方法，不能把网页商品宣传、他人体验或未核实功效移植为用户产品事实。
4. “账号数据中心”当前如实显示未连接状态和人工记录。用户在官方小红书页面登录不会自动把平台数据授权给本项目。

本地语义模型安装、固定版本、hash、缓存、CPU推理和关闭方法见 [本地 RAG 部署](LOCAL_RAG.md)。每次最多 256 个资料块参与语义检索，超限或缺少模型明确回退 BM25。旧文档“尚未接语义向量”描述过去版本，当前仅在本地模型可用时显示混合检索。

## 小红书授权与官方页面核对

用户已亲自在官方创作服务平台页面登录。本轮仅进行可见界面的只读核对：数据区显示按小时更新；技能集市提供上传 Skill 的入口，不能据此认定存在可供本项目使用的数据 API。未提取 Cookie，未下载该账号后台数据，未使用自动化连接器。

尚未取得适用于个人自然笔记、评论和流量的自动读取授权，项目仍为 not_connected，automatic_sync_available=false、last_sync_at=null。平台页面的小时更新也不支持秒级实时承诺。依据和可审阅的后续接入条件见 [小红书可行性核实](research/XHS_CONNECTION_FEASIBILITY.md)。

## 本轮实际验收环境

本轮浏览器和后台验收使用 **127.0.0.1:8775 与独立 PostgreSQL schema**。8765 正在运行另一 worktree；原默认数据库已有比当前分支更高的迁移版本，当前代码访问该默认库会得到 **SCHEMA_TOO_NEW**。未降级该库、删除迁移、重用其数据或替换8765服务。

因此，8775隔离环境验收成功不代表当前 checkout 的默认启动命令和默认数据库已可直接运行。后续正式切换需先核对代码与数据库版本、备份及选择匹配的迁移路径；不得为启动而篡改已应用迁移或绕过版本保护。部署入口见 [部署说明](DEPLOYMENT.md)。此处不记录连接串或账号凭据。

## 已取得的实际证据

- 浏览器中使用合成测试账号，以 Bing 执行防晒主题的真实后台研究；任务结果为 **partial**，成功读取并保存 **1 份知乎正文**，其他失败项随任务报告保留。它不是小红书案例采集成功，也没有真实热度证据。
- 浏览器实际下载研究 Markdown，文件为 **18570 字节**；检查包含来源、未知指标和研究范围。正文商品宣传仍为待核验来源，不升级为确定事实。
- 本地真实 BGE 模型已下载并执行；无共享中文 bigram 的“面部干燥怎么缓解”查询可召回“使用保湿乳液有助于肌肤水润”，无关汽车资料低于当前语义门槛而未召回。此为限定样本的检索接线验证。
- 案例与知识库的版本、隔离、删除、导出、事务取消/租约回滚已运行 SQLite 和真实 PostgreSQL 针对验证；收费模型与小红书自动同步不在已通过的实测范围内。主任务最终全量 Python **534 项通过、零跳过**，耗时198.758秒，包含真实 PostgreSQL；前端 Node **44 项通过**，前端脚本语法、角色卡同步和空白检查通过。该结果对应核心提交6afcf77及收尾测试，不包含付费模型质量或平台自动同步验收。

本轮未进行公网部署、真实平台发布或付费模型效果评测。网站账号、平台身份授权和平台数据授权是不同状态，不能互相替代。
