1. 审核同时含无效引用和更早轮次问题编号时，原免费恢复只处理一种错误，二次校验继续失败。现在组合保守恢复，保留本轮未解决问题、原始响应和用量；仍须重新审核。未知编号、缺少/重复本轮编号、未知用量、过期稿件、活跃任务仍阻断，不能免费整理成批准。

4. 实际首稿暴露用户要求350—500字与内部150—250字简稿提示冲突。明确用户长度要求优先。实际复审又把446个原始字符的人工稿估算成约332字，造成无效返修；审核现在接收程序计算的当前稿计数，按非空白Unicode字符（含标点/数字/英文字母），标题+正文不含CTA/标签。未以正则猜测任意自然语言要求，长度判断仍含模型环节，不承诺任意任务都满足字数。
5. 真实审核漏写 `issues[0].suggestion`，旧错误只显示 `text ... NoneType`。现在定位到具体字段，缺字段仍拒绝，不编造意见。
6. 无真实受众历史时的提示不再误称“模拟版”，授权门禁保持不变。
7. 旧实验预算是软目标；新增显式 `initialize(..., hard_limit=True)`，默认保持软目标。追加迁移8而不改旧SQL，事务内按全Token最高费率预留，失败未知用量阻断后续收费。创作/恢复/返修/普通AI对照同owner共享，本轮5元。未覆盖其他账号或旁路调用。
