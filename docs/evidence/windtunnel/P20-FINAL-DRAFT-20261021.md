# P20 Ultra基站预留尺寸与水电条件

装修给石头 P20 Ultra 留基站位，先把安装预留空间量准，再定水箱版还是上下水版。

先给结论，统一按宽×深×高排，单位厘米，三个数都是至少：

- 水箱版：宽 46、深 120、高 90
- 上下水版：宽 46、深 120、高 33

两版宽度和深度一样，差别在高度，也差别在要不要接水。深度是说明书里示意的整体预留深度，不是“基站后面留一份、前面再留一份 120”。上面这组是安装预留空间，不是基站本体尺寸，两者别混用。

## 水箱版和上下水版，各要什么条件

水箱版不接上下水，需手动加清水、倒污水；放置仍需满足预留空间、电源与柜门开合条件。

上下水版接自来水和排水，尺寸达标只是第一步。进水管是二分管、排水管是三分管，安装前要确认自来水水源、地漏或下水管、电源都能到位；进水压力要求在 0.1～0.4MPa，额定输入为 220–240V~ 50–60Hz。能不能接进水管、排水管能不能到地漏或下水管，得由专业人员勘测后判断，接不上就别硬装。接进水管前先把自来水放到清澈，避免杂质堵塞管路；新水管用包装内附带或官方指定的那根，别复用旧管或第三方管。

上下水版必须由石头授权专业人员上门勘测安装，请勿自行安装。自行安装会绕开官方勘测与配件规范，进水、排水一旦接错，既影响使用又难以保证安全，接不上时也不要硬装。

## 施工前把这 5 项逐条过一遍

1. 柜内或台面下的可用宽、深、高，是否达到所选版本的要求。
2. 柜门能关闭，基站能整体推入，前方留出操作空间；柜内净尺寸要同时容纳基站与进出水管线，别让柜门、踢脚线与插座、进出水口互相挡住。
3. 上下水版的进水管、排水管能否接到水源和下水，没条件先勘测；安装前确认自来水水源、地漏或下水管、电源都到位。
4. 插座位置和电压是否合适，额定输入为 220–240V~ 50–60Hz；基站放在硬质水平地面，远离明火、热源和积水。
5. 基站位置的 WiFi 要覆盖，别放阳光直晒处，也别用东西挡住信号区。

## 网上 45 / 47.5 厘米的说法，不能直接替换

网上说的“柜深留 45 厘米”“留 47.5 厘米”，不是这两份说明书中 B2 放置要求的数字，不能直接替换官方要求的深至少 120 厘米。柜深只做到 45～47.5 厘米时，明显低于官方整体预留深度，基站难以按说明书要求放置，进水管、排水管也缺少走线和操作余地；这种情况没有官方认可的替代方案，不要按网传数字硬留，应重新调整柜体或另选安装位置。看到别人的预留尺寸，先确认对方是哪个机型、哪个版本，Plus、活水版和 P20 Ultra 不能照抄。

安装或维护前，先让基站断电、机器人关机；已安装好的基站不要移动。

尺寸符合只是核对的一项，不等于一定装得上，上下水能不能通，以现场勘测为准。

先量好家里柜位的宽、深、高，评论区说说你更倾向水箱版还是上下水版。
