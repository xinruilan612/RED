## 二 页面会生成什么

条件卡（作者设定，5 条）：

1. 你能否在任务表工具界面上找到导出功能入口？如果找不到，你会希望它出现在哪个位置？
2. 导出时你会选择哪种文件格式？你是否清楚不同格式对中文内容的支持差异？
3. 导出中文表格时，你是否注意到编码选项？你能否判断该选哪种编码才能避免中文乱码？
4. 如果导出后的中文表格出现乱码，你能否根据现有说明自行排查并解决？
5. 在首次导出前，你是否清楚导出范围是整张表还是当前筛选结果？答案在说明中是否容易找到？

确认条件后启动检查。

## 三 第一次检查结果

| 条件 | 状态 | 原因 |
| --- | --- | --- |
| 入口 | unclear | 稿件未描述界面布局，无法定位入口 |
| 格式 | unclear | 稿件未说明可选格式 |
| 编码 | unclear | 稿件未提及编码或乱码 |
| 乱码排查 | unclear | 稿件没有排查步骤 |
| 导出范围 | unclear | 稿件未说明整表还是筛选结果 |

5 条全部 `unclear`。这不是“检查失败”，而是明确告诉作者：读者从当前正文找不到答案。

## 四 生成并采用补丁

页面会给出一个局部补丁：

修改前：

> 打开任务表，在菜单中选择导出，把文件保存到电脑。之后可以用表格工具打开。

修改后：

> 打开任务表，在右上角“更多”菜单中选择导出，把文件保存到电脑。导出格式选 CSV，编码选 UTF-8。之后可以用 Excel 或 WPS 打开。

补丁只改这一段，依据是材料中的“右上角更多菜单 / CSV / UTF-8 / Excel 或 WPS”。勾选采用后保存为新版本。

## 五 同条件复查

复查使用同一组 5 条条件、同一份材料：

| 条件 | 复查状态 |
| --- | --- |
| 入口 | pass |
| 格式 | unclear |
| 编码 | pass |
| 乱码排查 | unclear |
| 导出范围 | unclear |

结果：2 条通过，3 条仍保留未解决。  
这说明系统没有“改完就全部通过”；材料没覆盖的格式差异、乱码排查、导出范围仍然留在报告里。
