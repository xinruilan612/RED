# 三算法创新怎样讲清楚

## 一分钟说明

有迹将商品文稿创作拆成三个可计算的决策。

第一，决定写什么。将读者问题赋予权重，只让有本次资料依据的内容进入候选，在字数预算内选择重要问题覆盖更多、重复更少的组合。候选不超过12个时精确枚举，更多时用贪心回退。

第二，决定问什么。资料不足时，按重要性、新增可解决缺口、可回答程度和负担排序，最多问两个问题，允许跳过，不把未知编成事实。

第三，决定怎样组织。从参考文提取段落功能，只迁移适合当前资料的结构，不继承他人的参数与亲历。

四个Agent提出语义候选，程序执行约束与取舍，并留下能复算的记录。我们的创新是商品写作场景下的联合决策与工程闭环，经典覆盖理论、贪心和篇章组织思想都不是我们首创。
