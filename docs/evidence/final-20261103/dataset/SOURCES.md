## 保存了什么

`source_records.json`保存每源唯一URL、发布者、获取日、原始发布日期（仅Apple有明确日期）、实际已读文本的SHA256及长度、限定的短摘录和可复查段落/行号。短摘录按“每个汉字算一词、拉丁字符序列算一词”的保守方式计数，每源不超过25词，避免整页复制。

`retained_excerpt_text`是本地实际保留的短引文，`retained_excerpt_sha256`可直接重算；每个excerpt的retained_start/end均定位该字符串。`observed_capture.observed_text_sha256`是本次浏览器提取的已读可见文本（带工具行元数据）哈希，**不是原始HTML字节哈希，也不是已保存整页快照的证明**。为控制版权引用，未在交付目录归档整个网页；未来网页或提取格式改变，不一定能重现这一哈希。官方URL、获取日和行号用于人工回访。

`tasks.json`中facts的quote是研究者事实转述在**模型实际素材**中的精确片段，不冒充官网逐字引文；quote_kind已明确区分。其start/end使用Unicode码点、左闭右开索引，每条满足material[start:end] == quote。每项同时关联source_id、官网URL、网页行号以及短摘录ID；没有足够版权预算保留完整原句的细节，保留行段定位并由独立人员回读确认。

## 来源许可与解释边界

公开可访问不等于获得重新分发整页或图片的许可。这里只有限引用和自主事实转述，未复制产品图片、用户评论、商标图形或大段营销文案；品牌名称仅为识别任务对象。品牌声明和官方参数也不是独立实测。若将生成文章公开发布，仍需单独检查实际账号、素材权利、时效和人工确认。

三类各两题体现领域跨度，但每类只有两题；来源数量和任务数量均不能替代样本代表性。六个构造需求、权重和事实对应均为研究者拟定，等待独立人工确认，不声称已完成人工金标。
