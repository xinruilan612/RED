# Windows免费流程与录像验收

本轮只验证免费模拟，不填写模型密钥、不启动真实AI。它核对Windows兼容性与操作链路，不能作为真实模型质量或用户效果。回执初始十项均为NOT_RUN，实际做过才填PASS或FAIL。

## 在Windows电脑操作

完整解压最终目录中的有迹-省赛最终交付-Windows-x64-20261103.zip，保留全部相对目录。记录Windows版本和位数，并从根目录交付校验.json记录source_commit。双击一键启动.cmd，用启动器打开的实际网址进入；第一次使用创建一个单独的测试账号。

新建小红书创作，保持“模拟流程（免费，不调用模型）”，输入主题“M650连接方式”，读者“本机测试人员”，资料“低功耗蓝牙或Logi Bolt USB接收器连接；购买前核对具体系统与接口”。保存后连续运行到人工处理。确认页面显示真实模型调用0次、费用0。

点击“我来修改文案”，标题改为“M650连接前先核对”，正文改为“连接方式包括低功耗蓝牙和Logi Bolt USB接收器。购买前请核对你的设备系统及接口。本稿仅用于免费流程验收。”保存为新版本，检查版本数为2，旧审核不能直接用于确认新稿。

点“复审当前版本”，完成免费模拟复审后确认当前版本。下载Word，打开核对标题与正文确为版本2；刷新页面，检查已确认状态和版本仍保留。最后关闭启动器，核对页面服务退出。失败就记录报错和卡住步骤，不需要反复重装或填假通过。

## 录像及回执

建议登录完成后开始录像，从已登录的新建创作页录到修改、复审、确认与下载Word，约3至5分钟。保留模拟模式和0调用状态。剪去等待可以，但注明剪辑，不把免费模拟说成真实AI。录制不需要展示密码、恢复码或个人资料。

将十项结果填入同目录Windows免费流程验收回执.csv；实际现象写在observed_result，无法操作保持NOT_RUN。记录Windows版本、发布源码提交，以及截图或视频文件名。将填写后的CSV和录像交回即可，不必发送个人数据库、日志密钥或账号。

独立评分是另一项任务：只把03评审/公开资料三对六稿中各自的reviewer-xx-独立评审.zip交给对应评审者，每人评同样6稿但顺序已随机。不要把researcher-private映射或算法组别一起发送。评审后下载其CSV，不能把Windows操作人的表现自动变成稿件评分。
