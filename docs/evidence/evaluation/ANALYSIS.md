## 二 结果

| 组 | n | 事实支撑率 | 要点覆盖率 | 禁用断言率 | 平均正文字数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| **A** 单次直写 | 6 | **37.5%** | **83.3%** | 0.0% | 197 |
| **B** 多 Agent · 关检索 | 6 | **52.8%** | 65.6% | 0.0% | 164 |
| **C** 多 Agent · 分类检索 | 6 | **64.1%** | 65.8% | 0.0% | 159 |

### 2.1 归因拆解（本文最有价值的一段）

事实支撑率的增量可以干净地拆成两个来源：

```
A 单次直写            37.5%
   ↓ +15.3pp  ← 多角色流程的贡献（B − A）
B 多 Agent 无检索      52.8%
   ↓ +11.3pp  ← 分类证据检索的增量（C − B）
C 多 Agent + 分类检索  64.1%
```

**这意味着两件事都有效，但贡献不同**：多角色结构把可核查内容提升了约 15 个百分点，分类检索在此基础上再提升约 11 个百分点，合计 **+26.6pp（1.7 倍）**。

### 2.2 成本

| 组 | 单次运行成本 | 相对 A |
| --- | ---: | ---: |
| A | $0.00064 | 1× |
| B | $0.0296 | 46× |
| C | $0.0338 | **53×** |

C 相对 B 只贵 14%，却多换来 11.3pp 事实支撑——**检索这一步的性价比明显高于从 A 升级到 B**。

## 三 预注册假设的检验结果

按 `rubric.md` 第六节，逐条给出结论，**包括被推翻的**：

| 假设 | 预期 | 实测 | 判定 |
| --- | --- | --- | --- |
| **H1** | C 的事实支撑率高于 A | 64.1% vs 37.5% | ✅ **成立** |
| **H2** | C 的禁用断言率低于 A | 0.0% vs 0.0% | ❌ **未成立**（两组均为 0） |
| **H3** | B 的要点覆盖率高于 A | 65.6% vs 83.3% | ❌ **被推翻**，A 明显更高 |
| **H4** | C 成本高于 A，但提升幅度大于成本增幅 | 成本 53×，支撑率 1.7× | ❌ **未成立**（成本增幅远大于质量增幅） |

**H2 未成立的实际原因**：两组自动指标都是 0，说明在这个题库上禁用断言没有区分度——见第五节的盲区说明，这一条**不能**表述为「两组都没有问题」。

**H3 被推翻是本次最重要的反直觉发现**：单次直写一次拿到全部材料，写出来的内容**覆盖更完整**；多角色流程受阶段约束和上下文裁剪影响，覆盖反而更窄。

**H4 未成立要如实写进材料**：按 token 计，多 Agent + 检索的成本约为单次直写的 53 倍。它的价值不在省钱，而在**减少人工核对**——这一点需要用人工修改率来证明，本次尚未测量。

## 四 关键定性发现：无资料时，单次直写会编造，流程会拒绝

G05（美妆换口播）在题库中**故意不提供任何事实资料**（`facts: null`），期望行为是「收窄承诺、不编造规格」。三组的实际表现：

**A 组（单次直写）编造了完整的产品规格**：

> 它目前共 3 个色号：B01-1 暖杏粉｜B01-2 蜜桃棕｜B01-3 焦糖红
> 全系采用磨砂雾面管身，配金属质感旋盖，按压式滴管设计…

而题库中该产品**只有名称**，没有任何色号与包装信息。这些内容是模型凭空生成的。

**B 组**：

> B01 是型号标识，不是色号本身……信息不全时，以实物为准。

**C 组**：

> 目前公开渠道未查到雾桃B01唇釉的官方色号列表、包装说明或参数资料。所有信息请以你手中实物瓶身为唯一依据。

**B 和 C 都正确地承认了资料缺失，A 编造了三个色号加包装细节。**

这条发现比任何百分比都更有说服力：它说明多角色流程与证据约束的实际作用不是「写得更好看」，而是**在没有依据时拒绝编造**——这正是内容创作者最容易被平台与读者反噬的地方。

> ⚠️ 诚实标注：这条结论来自对 1 个样本的人工阅读，不是统计结果。且**自动指标没有抓到它**（见下节）。

## 五 指标局限（必须随结论一起披露）

### 5.1 禁用断言的盲区

本次 G05 中 A 组编造的规格，**自动指标判定为 0 命中**。原因是题库的禁用模式在实验前只写了「晚霞被我装进了口袋的第七层」和「试用 N 天」两条，没有预见到「编造色号与包装」这种形态。

**结论**：禁用断言率只能检测**已预见**的违规形态，不能证明稿件无编造。任何「0 命中」都不得表述为「无事实错误」。

### 5.2 否定语境的启发式

初版指标把「**无**持妆时长、保湿效果等**未提供数据**」判为违规，把最谨慎的稿件打成最差的稿件。修正后（`rubric.md` §3.3）识别 `未提供/未引申/未标注` 等缺失声明，重新离线判分得到本文数据。

**该修正没有重跑模型**，只是重新计算，因此不影响成本与样本，但说明这类指标必须配人工抽检。

### 5.3 要点覆盖率的词面偏差

G05 的评分点是结构性的（「开场提出选色问题」「镜头展示管身」），而指标用中文 bigram 词面重叠计算，三组均判为 0%。这是指标的失效，不是三组都写错了——实际三组都写了开场提问，只是措辞不同。

**因此要点覆盖率只用于组间比较，不用于绝对判定**，且 G05 这一题在该指标上应视为无效样本。

### 5.4 样本量

n=6，按 rubric 只能表述为**初步观察**，不构成统计结论。
