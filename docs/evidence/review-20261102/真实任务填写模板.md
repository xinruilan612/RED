# 真实任务填写模板

先发一个任务即可，我会核对资料并拟定必答问题，确认后再生成。无需一次交齐6个。

## 任务1

主题：
目标读者：
平台与形式：小红书图文（可改）
目标篇幅：约300字（可改）
希望读者看完能解决的问题：
原始资料正文或文件：
资料出处、版本/日期（有则填）：
你有权使用这些资料吗：
哪些参数/结论已经确认：
哪些未知、不能推断：
是否有本人真实使用记录：没有 / 有，原始记录如下
是否有可借鉴写法的授权参考：没有 / 有，原文与出处如下

不要填写模型密钥、账号密码或他人隐私。参考文章中的作者经历不能当你的经历。

任务2-6按同样格式逐步提供，建议三个领域各2个；不为凑领域或数量编造任务。若素材不足，先做较少的真实任务并如实报告。

## 生成前由组织者和任务提供者确认

- 2-5个必须回答的读者问题。
- 每个问题的重要程度与支持资料位置。
- 允许的推断、未知与必须保留的条件。
- 两组共同事实集合，补料实验是否单列。
- 预先确定失败/重试政策，不能只挑成功稿送评。

这些填写完成不等于已经取得评审分数或真实试用结果。
