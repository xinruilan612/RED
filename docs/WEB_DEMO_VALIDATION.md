## 明确限制

- 仅固定模板模拟；少量禁用承诺词检查是真实执行的本地规则，其余审核维度为明确标注的模拟结果。
- 没有真实模型、联网搜索、跨任务记忆、完整角色 Schema 或付费调用；显示零调用和零费用属实。
- 每次“下一步”在服务端事务内完成，前端拿到完成结果后展示。不提供执行中 token 流或后台持续运行；关闭页面停止发起下一步，不丢已保存记录。
- 会话是本机随机 Cookie，不是正式账号系统。生产部署仍需完整认证、HTTPS、限流、队列/租约等。
- 仅导出 Markdown；图文渲染、云端部署仍待实现。
