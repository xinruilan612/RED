## 三、测试覆盖与判定

| 范围 | 关键检查与预期 |
| --- | --- |
| 状态与版本 | 拒绝非法状态、旧稿件批准及编辑后过期审核；新稿复审后可确认 |
| 身份与权限 | 跨用户及跨账号访问拒绝；CSRF 与来源校验；密码恢复撤销旧会话 |
| 资料与来源 | 版本、页码与位置保留；停用排除新检索；错误引用拒绝；原快照保留 |
| **分类检索** | 三组过滤先于排序；跨账号资料不进入候选；型号不匹配淘汰；向量失败按组降级且不冒充语义结果；正常零命中不补齐 |
| **引用校验** | `source_id` 必须存在；`quote` 必须逐字存在于来源；审核 `excerpt` 必须存在于当前稿件 |
| 模型与费用 | 预算预留、路由冻结、结构错误记录、未知用量不重发 |
| 后台执行 | 并行分支复用、暂停继续、取消优先、旧租约提交拒绝 |
| 进程恢复 | SIGKILL 后新进程恢复，已提交节点及已收到响应不重复应用 |
| 运营分析 | 同口径历史、中位数门槛、缺失值保留、修正和撤销失效传播 |
| API 与数据迁移 | 实际 HTTP、迁移重复/冲突/回滚及校验和 |
| **评测框架** | 题库校验、指标确定性复算、报告生成与失败样本保留 |

### （一）代表性恢复用例

`test_sigkill_after_response_and_commit_resumes_without_duplicate_calls` 启动实际子进程 Worker，分别在响应保存后与业务提交后终止进程；等待租约过期后启动新进程，检查稿件到达人工确认且阶段产物没有重复。该用例同时覆盖 SQLite 与 PostgreSQL 路径（本轮 PostgreSQL 路径跳过）。

`test_successful_parallel_sibling_survives_other_failure` 让一个并行分支成功、另一个失败，恢复时检查成功分支不再调用。`test_unknown_transport_does_not_repeat_paid_call` 验证未知传输结果阻断而非自动重发。

### （二）代表性证据与审核用例

`test_public_material_snapshot_and_audit_survive_live_fixture_graph` 验证资料 URL、证据快照与调用台账贯穿角色执行，其模型为测试替身。模型路由测试另行检查：替换审核模型返回 `approved` 但必过项失败时，后端仍拒绝。这些证明**程序守卫行为**，不证明模型事实理解准确。

### （三）本轮新增的评测框架用例

`tests/test_evaluation_metrics.py`（16 项）与 `tests/test_evaluation_bench.py`（13 项）验证：题库结构校验对缺失字段、重复 ID、非法正则报错；指标可从零复算且不信任已存分数；报告必须列出失败样本并标注「不是事实核查通过」；空稿不产生误报。指标层不联网、不调模型。

## 四、本轮修复的缺陷

以下缺陷均由本轮复验实际暴露并修复，修复后对应的回归用例通过。

| 缺陷 | 影响 | 修复 |
| --- | --- | --- |
| 打包脚本遍历祖先目录判定符号链接 | macOS 上 `/var` 是指向 `/private/var` 的符号链接，导致打包工具与其 10 项测试在该平台**完全不可用** | 只检查传入目录本身；树内符号链接仍由逐文件、逐目录检查拒绝 |
| 打包/启动器测试使用未解析的临时目录 | 13 项路径断言失败，开发机无法得到全绿结果 | 测试入口统一 `resolve()` 后比较 |
| 连接器登录与绑定互为前置 | `bind` 需要已登录、登录需要已绑定，**全新安装无法从网页连接小红书** | 未绑定账号可先取登录二维码；新增独立绑定接口并在绑定前校验身份 |
| 连接器令牌使用相对路径 | 进程工作目录下不存在该文件，登录请求直接报错 | 令牌路径支持 `YOUJI_XHS_TOKEN_FILE`；缺失时返回可操作错误而非崩溃 |
| 打包启动器无法透传令牌路径 | 源码检出与运行包无法共用同一连接器 | 启动器透传该路径，并默认指向运行包内位置 |
| 未绑定视图没有登录入口 | 用户看不到「连接小红书」按钮 | 未绑定视图新增「连接小红书」面板与「完成连接」流程 |

> 说明：第 1～2 项属于打包工具链，不改变业务逻辑；第 3～6 项属于连接器接入路径。两类修复均附带回归用例。

## 五、历史真实模型与浏览器验收

以下为历史记录，**本轮未复跑**，单独列示，不与本轮计数混算。

### （一）真实模型闭环

在明确预算授权内完成资料 → 四角色 → 新稿 → 审核闭环，结果为生成正文、审核通过、`WAITING_USER`、`human_accepted=false`，即仍等待用户最终确认，未发布。后续在累计 1 元授权内完成真实 `qwen-plus` 连接测试、资料校对入库、生成、对话改稿、复审、确认与导出；全部调用逐次预留，未知用量不重发。

### （二）真实公开检索与入库

真实联网任务中实际读取公开正文（含官网与第三方页面），保存正文哈希、抓取时间与读取记录；来源与摘要严格区分，未读摘要不参与检索。候选确认后才进入资料库，重复确认保持幂等。

### （三）连接器真实读取

本人账号只读连接在授权后完成有限轮询；会话失效时明确提示重新登录，未被当作「空结果」。视频来源仅保存文字说明，不称已看视频或转写音轨。

### （四）浏览器操作

历史记录在 1280×720 视口完成资料检索与模拟创作，页面无整体横向溢出；免费模拟任务完成创建、后台执行、人工修改、复审、确认与导出，真实模型调用 0。历史记录中「第 3 个节点保存后关闭浏览器、Worker 继续完成其余节点」的浏览器行为，**本轮没有重新录制**；本轮复验的是自动化套件中的实际进程恢复路径。模拟内容显著标注为模拟，不作为模型质量证据。

## 六、结论外推边界

本节说明哪些结论不能由本报告推断，避免把局部验证当成整体结论：

1. **数据库路径**：本轮以 SQLite 路径执行，231 项 PostgreSQL 集成用例按条件跳过、不计入通过；PostgreSQL 历史验证记录见第五节。
2. **模型质量**：自动化用例使用测试替身，回答的是守卫行为；生成质量由 7.3 的三组真实模型对照回答。
3. **语义检索效果**：向量路径的检索质量未在自动化套件内单独度量，其增益由 7.3 中 C 组与 B 组的差值体现。
4. **读者偏好**：内容风洞的读者结论按 7.4 的盲评方案采集与判分，自动指标不替代真人判断。
5. **并发与兼容**：并发压测、全浏览器兼容矩阵、独立安全审计属于上线前的独立验证项，与本轮工程复验分开记录。

## 七、评测体系与后续

### （一）已建成的评测框架

评测层已从「只有行为契约测试」扩展为「行为契约 + 质量指标」两层：

- `backend/evaluation.py`：确定性纯函数指标，不联网、不调模型，任何人可用同一份结果复算；
- `docs/evidence/evaluation/gold_set.json`：7 题预注册题库，32 个评分要点、26 条禁用断言；
- `docs/evidence/evaluation/rubric.md`：评分标准与 4 条可被推翻的假设，实验前冻结；
- `scripts/evaluation_bench.py`：自检、判分、报告生成与受权真实执行。

### （二）三组对照设计

| 组 | 配置 |
| --- | --- |
| A | 单次模型调用，无检索、无多角色 |
| B | 生产四角色流程，检索关闭 |
| C | 生产四角色流程，三组分类检索开启 |

指标：事实支撑率、禁用断言率、要点覆盖率、人工修改率、返修轮次、成本与耗时。

### （三）实验执行结果（2026-10-18）

六个真实模型场景 × 三组，**18 次运行全部成功**，总成本 0.384 美元：

| 组 | n | 事实支撑率 | 要点覆盖率 | 禁用断言率 | 平均正文字数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A 单次直写 | 6 | 37.5% | 83.3% | 0.0% | 197 |
| B 多 Agent · 关检索 | 6 | 52.8% | 65.6% | 0.0% | 164 |
| C 多 Agent · 分类检索 | 6 | **64.1%** | 65.8% | 0.0% | 159 |

**成立的预期**：C 的事实支撑率高于 A（+26.6pp，1.7 倍）。**未成立的预期如实保留**：C 的禁用断言率未低于 A；B 的要点覆盖率低于 A，即单次直写覆盖面更完整。

**指标盲区（实测发现）**：一题故意不提供事实资料时，A 组编造了三个色号与包装细节，而自动禁用断言指标判为 0 命中——因实验前预注册的模式未覆盖该形态。**因此「禁用断言率 0」不能表述为「无事实错误」**。

**边界**：n=6，仅为初步观察；未测量真人读者偏好、投放效果或商业收益。

### （四）真人盲评方案

自动指标只能测可计算的部分。读者偏好通过匿名盲评采集：6 组真实成稿、每组两个版本、左右位置按固定种子随机且对半，评审人不知道哪版来自哪一组。

- 材料：`docs/evidence/evaluation/human-review/PACKET.md`（评审人看）
- 答题表：`ANSWER_SHEET.csv`（3 个问题：更易读、更可信、更愿意用）
- 对照表：`KEY_RESEARCHER_ONLY.json`（不随材料发出）
- 判分：`scripts/build_human_review.py --decode 回收表.csv`

回收后按预注册规则判分，结果单独记录，不与自动指标混算；本报告第 7.3 节的数据全部来自自动指标。

### （五）后续条件

变更模型、提示词、检索参数或协作逻辑后，须重新执行相应回归并更新基线。真实模型评测需独立记录模型版本与用量，不能用替身结果替代。公开搜索的时效性与相关性需单独评测。
