# 有迹测试报告

AI+软件创新 | 团队编号 47191919 | 软件版本 0.8.0 | 产品基线 2026-10-13

本报告记录 2026-10-13 交付基线的工程复验，并单列历史真实模型试运行与浏览器验收。测试结论只适用于下列环境与范围：替身模型证明的是守卫行为，真实模型的生成质量由附录 B 第五节的三组对照实验回答。

## 一、测试环境与结果

测试对象包括 `backend`、`frontend` 及 `docs/design` 中的机器契约，覆盖创作状态机、身份与权限、账号与运营、分类证据检索、引用校验、模型调用边界、FastAPI 接口与持久后台执行。

| --- | --- |
| 操作系统 / 架构 | macOS 27.0.0（Darwin）、arm64；Python 3.12.14，依赖全部锁定 |
| 数据库 | 本轮使用 SQLite 路径；PostgreSQL 集成用例按条件跳过，**不计入通过** |
| 前端测试 | Node.js `node:test` |

后端执行 `python -m unittest discover -s tests`，输出 `Ran 1189 tests in 41.426s — OK (skipped=234)`：

| 结果 | 数量 | 说明 |

**环境观察如实保留**：更早一次受限 shell 中运行同一套件时，`test_timeout_kills_detached_descendant_but_keeps_unrelated_process` 调用 `/bin/ps` 检查子进程存活被拒（`PermissionError`），当时记为 1 项错误；该用例属执行环境的进程检查限制、不是产品逻辑缺陷，常规终端复跑后全量返回 `OK`。本节以复跑结果为准。

| 评测框架 | 题库校验、指标确定性复算、报告生成与失败样本保留 |

代表性用例：`test_sigkill_after_response_and_commit_resumes_without_duplicate_calls` 启动真实子进程 Worker，在响应保存后与业务提交后分别终止进程，等待租约过期后启动新进程，检查稿件到达人工确认且阶段产物没有重复；`test_successful_parallel_sibling_survives_other_failure` 让一个并行分支成功、另一个失败，恢复时成功分支不再调用；`test_unknown_transport_does_not_repeat_paid_call` 验证未知传输结果阻断而非自动重发。`test_public_material_snapshot_and_audit_survive_live_fixture_graph` 验证资料 URL、证据快照与调用台账贯穿角色执行；模型路由测试另行检查：替换审核模型返回 `approved` 但必过项失败时后端仍拒绝。这些证明**程序守卫行为**，不证明模型事实理解准确。本轮新增评测框架用例 29 项，验证题库结构校验对缺失字段、重复 ID、非法正则报错，指标可从零复算且不信任已存分数，报告必须列出失败样本。

## 三、三组对照实验

质量指标层的执行细节与配置见附录 B 第六节，本节只列与本报告相关的结论。2026-10-18 执行六个真实模型场景 × 三组，**18 次运行全部成功**，模型 `qwen-plus`，总成本 0.384 美元：

| 组 | n | 事实支撑率 | 要点覆盖率 | 禁用断言率 | 平均正文字数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A 单次直写 | 6 | 37.5% | 83.3% | 0.0% | 197 |

## 四、本轮修复的缺陷

| 缺陷 | 影响 | 修复 |
| --- | --- | --- |
| 打包脚本遍历祖先目录判定符号链接 | macOS 上 `/var` 指向 `/private/var`，打包工具与其 10 项测试在该平台完全不可用 | 只检查传入目录本身；树内符号链接仍由逐文件检查拒绝 |
| 打包 / 启动器测试使用未解析临时目录 | 13 项路径断言失败，开发机得不到全绿结果 | 测试入口统一 `resolve()` 后比较 |
| 连接器登录与绑定互为前置 | 全新安装无法从网页连接小红书 | 未绑定账号可先取登录二维码，新增独立绑定接口并校验身份 |
| 连接器令牌用相对路径、启动器未透传路径 | 登录请求报错；源码检出与运行包无法共用连接器 | 令牌路径支持环境变量指定并在启动器透传，缺失时返回可操作错误 |

**读者偏好的采集方式**：自动指标只能测可计算的部分，读者偏好通过匿名盲评采集——取 6 组真实成稿、每组两个版本，左右位置按固定种子随机且对半，评审人不知道哪版来自哪一组；评审包为 `docs/evidence/evaluation/human-review/PACKET.md`，答题表 `ANSWER_SHEET.csv` 提三个问题（更易读、更可信、更愿意用），对照表 `KEY_RESEARCHER_ONLY.json` 不随材料发出，回收后用 `scripts/build_human_review.py --decode` 按预注册规则判分，结果单独记录、不与自动指标混算。

**历史验收（本轮未复跑，单独列示、不与本轮计数混算）**：在明确预算授权内完成资料 → 四角色 → 新稿 → 审核闭环，结果为生成正文、审核通过、`WAITING_USER`、`human_accepted=false`，仍等待用户最终确认、未发布；后续在累计 1 元授权内完成真实模型连接测试、资料校对入库、生成、对话改稿、复审、确认与导出，全部调用逐次预留、未知用量不重发。真实联网任务实际读取公开正文并保存哈希、抓取时间与读取记录，来源与摘要严格区分、未读摘要不参与检索；本人账号只读连接在授权后完成有限轮询，会话失效时明确提示重新登录而非当作空结果，视频来源仅保存文字说明、不称已看视频或转写音轨。

## 五、结论与结论外推边界

交付基线在本报告列明的环境中，**955 项断言通过、234 项因外部条件跳过、0 失败 0 错误**，覆盖状态机、权限隔离、分类检索、引用校验、费用守卫、进程恢复与评测框架。

以下结论不能由本报告推断：①数据库路径——本轮以 SQLite 执行，231 项 PostgreSQL 集成用例跳过、不计入通过；②模型质量——自动化用例使用测试替身，回答的是守卫行为，生成质量见附录 B 第五节；③语义检索效果——向量路径的检索质量未单独度量，其增益由 C 组与 B 组的差值体现；④读者偏好——由匿名盲评方案采集与判分，自动指标不替代真人判断；⑤并发与兼容——并发压测、全浏览器兼容矩阵与独立安全审计属上线前的独立验证项。

变更模型、提示词、检索参数或协作逻辑后，须重新执行相应回归并更新基线；真实模型评测需独立记录模型版本与用量，不能用替身结果替代。三组对照与风洞实验的原始数据随佐证材料提交，可用 `backend/evaluation.py` 与 `scripts/evaluation_bench.py` 离线复算。
