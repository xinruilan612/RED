## 二 E2 三组对照实验（18 次真实模型运行）

**证明什么**：在相同素材、相同模型、相同预算下，「多角色协作 + 三组分类检索」比单次直写更容易产出有依据的内容。

**实验设计**：

| 组 | 配置 | 材料去向 |
| --- | --- | --- |
| A | 单次模型调用完成全部输出，无检索、无多角色 | 材料拼入单条提示词 |
| B | 生产四角色流程，检索关闭 | 材料作为任务背景 |
| C | 生产四角色流程，三组分类检索开启 | 材料入库后按分类检索 |

控制变量：同一模型（`qwen-plus`）、同一批素材、同一预算上限、同一天内执行，记录代码哈希与提示词版本。题库 `gold_set.json` 7 题 / 32 个评分要点 / 26 条禁用断言，评分标准 `rubric.md` 在实验前冻结、实验后未修改。

**总体结果（2026-10-18，18 次运行全部成功，总成本 0.384 美元）**：

| 组 | n | 事实支撑率 | 要点覆盖率 | 禁用断言率 | 平均正文字数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A 单次直写 | 6 | 37.5% | 83.3% | 0.0% | 197 |
| B 多 Agent · 关检索 | 6 | 52.8% | 65.6% | 0.0% | 164 |
| C 多 Agent · 分类检索 | 6 | **64.1%** | 65.8% | 0.0% | 159 |

**归因拆解**：多角色结构贡献 +15.3 个百分点（B − A），分类检索再贡献 +11.3 个百分点（C − B），合计 **+26.6pp，为 A 组的 1.7 倍**。成本上 C 约为 A 的 53 倍，相对 B 仅增 14%。

**逐条样本**（事实支撑率 / 要点覆盖率 / 正文字数）：

| 题号 | A 单次直写 | B 多 Agent 无检索 | C 多 Agent + 分类检索 |
| --- | --- | --- | --- |
| G01 | 75.0% / 100.0% / 170 | 75.0% / 100.0% / 160 | 66.7% / 100.0% / 119 |
| G02 | 40.0% / 100.0% / 220 | 75.0% / 50.0% / 137 | 75.0% / 75.0% / 162 |
| G03 | 16.7% / 100.0% / 174 | 66.7% / 83.3% / 169 | 42.9% / 100.0% / 211 |
| G04 | 33.3% / 100.0% / 208 | 33.3% / 60.0% / 208 | 100.0% / 60.0% / 146 |
| G05 | 0.0% / 0.0% / 186 | 0.0% / 0.0% / 130 | 0.0% / 0.0% / 210 |
| G06 | 60.0% / 100.0% / 223 | 66.7% / 100.0% / 183 | 100.0% / 60.0% / 107 |

**同组数据能支持与不能支持的两件事**：

- 支持：C 组事实支撑率高于 A 组（+26.6pp）。
- 不支持：C 组禁用断言率低于 A 组——两组均为 0，本实验未观察到差异；B 组要点覆盖率低于 A 组（65.6% vs 83.3%），即单次直写的覆盖面更完整。

**指标盲区记录**：G05 一题故意不提供任何事实资料。A 组编造出三个色号与包装细节，B、C 两组明确声明资料缺失、以实物为准。自动指标未命中该形态，因为答题前预注册的禁用模式未覆盖它。因此「禁用断言率 0」不能表述为「无事实错误」，该盲区已记录。

**原始文件**：`docs/evidence/evaluation/REPORT.md`（报告）、`results-20261018-221902.json`（原始结果）、`results-20261018-221902.scored.json`（判分结果）、`gold_set.json`、`rubric.md`。

## 三 E3 内容风洞：12 条条件实验与代理读者盲评

**证明什么**：把「这篇稿子讲清楚了吗」拆成可核查条件后，系统能定位未讲清项，并生成绑定原句的局部补丁；复查如实保留未解决项。

**实验对象**：P20 Ultra 尺寸稿（真实账号资料库中的尺寸核对表 + 官方上下水版说明书摘录），12 条条件来自公开网页常见问题线索、由作者设定。

**结果（2026-10-21，真实 AI 模式）**：

| 阶段 | 结果 |
| --- | --- |
| 原稿条件评估 | 4 条通过、8 条未讲清 |
| 首次读稿 | 5 条判定 `unclear`（5/5） |
| 补丁 | 1 个实质补丁，绑定段落槽位与原句 |
| 同条件复查 | 2 条 `pass`、3 条保留未解决 |

保留未解决项是本机制的设计要求：复查不把未解决项改判为通过，也不补齐无依据的内容。

**未讲清的 8 条问题**（摘要）：45 / 47.5 / 120 厘米分别在什么条件下成立；没有地漏或水龙头时上下水版能否安装；条件不满足时如何取舍；网上说法可信度如何判断；P20 Ultra 与 Plus / 活水版尺寸能否通用；柜门、管线、机器推不进去的风险；先给结论还是先讲条件；「120 厘米」是否前后都要留。

**代理读者盲评（2026-10-07，六个独立代理 × 18 次阅读）**：

| 指标 | 原删节控制稿 | 风洞最终稿 |
| --- | ---: | ---: |
| 答案定位（命中正确答案） | 0 / 45 | 32 / 45 |
| 完整任务成功率 | 0 / 9 | 0 / 9 |

因此本文只主张「定位到答案的能力提升」，不主张「完整任务成功率提升」：同一组数据支持前者、不支持后者，两者分开记录。代理阅读由独立子代理按冻结任务与盲评分规则完成，评分类似人工流程但不等同真人。

**累计真实请求**：162 次实际模型请求，费用上界 2.118922 元（含 0.042810 元未知用量预留，已按守卫规则阻断）。

**原始文件**：`docs/evidence/windtunnel/P20-EXPERIMENT-20261021.md`、`ACCEPTANCE-20261021.md`、`docs/windtunnel/agent_study/`（原始回答、冻结哈希、判分）、`docs/windtunnel/STUDY_PROTOCOL.md`（研究协议：10 篇样本、3 篇探索、7 篇留出、6 位读者、42 次盲评分配）。
