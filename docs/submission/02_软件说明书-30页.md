# 有迹软件说明书

AI+软件创新 | 团队编号 47191919 | 软件版本 0.8.0 | 产品基线 2026-10-13

## 一、软件用途和使用条件

有迹用于小红书图文稿与抖音口播、分镜脚本的辅助创作，并支持账号历史与运营复盘。用户提供需求与合法使用的材料，对最终稿件负责；发布动作、成片拍摄与平台合规由创作者按平台规则完成，软件负责稿件与脚本的文本、版本与依据。

网站身份用于登录与数据隔离；页面中的社媒账号档案用于创作定位，不等于已获得平台授权。免费模拟模式可检查操作流程，但固定模板内容不能证明真实模型质量；真实模式调用第三方模型会产生费用，需先配置并确认可用预算。软件提供网页操作界面，正式入口为 FastAPI 服务：源码部署默认 `http://127.0.0.1:8765/`，Windows 运行包由启动器自动选择端口（优先 8890）并打开浏览器。

## 二、界面与页面

软件为单页应用，左侧导航进入六个页面，同一账号下的资料、任务与产物在各页之间贯通：

<!-- cols: 0.20,0.80 -->
| 页面 | 主要功能 |
| --- | --- |
| 概览 | 账号与连接状态、进行中的任务、最近产物与待处理确认 |
| 创作台 | 需求输入、模拟 / 真实模式选择、执行进度、角色产物查看与人工确认 |
| 资料库 | 导入、预览校对、资料用途分类、版本与原文定位 |
| 内容风洞 | 条件设定、读稿、核验、补丁、复查与报告导出 |
| 发布与运营 | 发布记录、24 / 72 / 168 小时指标、观察与单变量实验建议、周计划 |
| 连接与设置 | 社媒账号档案、小红书扫码连接、模型与预算设置 |

## 三、操作流程

**① 登录与账号档案**。注册时设置 8—20 位、含大小写字母的密码，保存一次性恢复码备用。建立社媒账号档案，填写平台、定位、受众、表达偏好与禁用表达；软件用稳定 `account_id` 关联记录，改昵称不会生成新身份。历史作品与指标按需录入，只填有依据的信息，缺失项保留未知；模拟数据不进入真实 AI 上下文。忘记密码用恢复码重设，旧会话即被撤销。

**② 资料入库**。粘贴文本或上传 UTF-8 TXT、Markdown、文本型 PDF、DOCX（单份 ≤3,000,000 字节、PDF ≤50 页、正文 ≤100,000 字符），保存前可预览校对。导入时须选择**资料用途**，它决定资料进入哪一组检索：

| 用途 | 检索组 | 可用于 |
| --- | --- | --- |
| 写作材料 / 待核验事实 | `facts` 事实组 | 可被引用、需注明来源的规格与结论 |
| 写法参考 | `examples` 样例组 | 只学结构与表达，**不能被当作事实引用** |
| 通用方法 | `methods` 方法组 | 跨领域的写作方法 |

同一来源可按不同用途分别保存。检索只使用当前账号的有效资料；更新创建新版本；移出资料库后新任务不再检索，但旧版本与任务证据仍保留。

**③ 创建与执行**。选择账号与目标平台，填写选题、目标读者、风格与素材，需要时勾选检索并核对取回来源。软件把相关原文、账号上下文与路由策略保存为任务快照。选择模拟或真实 AI 模式后提交「后台运行到人工处理」；后台不会因浏览器关闭而停止（数据库与 Worker 需保持运行）。进度展示的是已保存的执行事件，不是质量评分。

**④ 补料与返修**。资料不足时按问题补充事实，避免要求模型编造亲历经历或统计；审核提出意见后可在当前额度内继续自动返修或手动编辑。错误、超时与用量未知不会自动无限重试，达到次数或预算限制时应检查原因。

**⑤ 版本确认与导出**。换标题或改正文都会产生新版本；阅读差异后重新审核，只有当前有效审核对应的稿件可以确认。确认后可下载 Markdown 或**可编辑的 Word 确认稿（.docx）**（含标题、正文、互动引导与标签，并标注确认方式）。确认表示用户接受该版本，不表示平台已发布或通过平台审核；未通过 AI 审核但用户决定采用时，文档标注「人工采用、未通过 AI 审核」，不伪装成审核通过。

**可选：连接小红书**。在「连接与设置 → 账号数据连接」扫码登录并「完成连接」，系统核对账号身份后才写入绑定。连接器为只读，仅读取本人公开笔记与已保存评论，**不发布、不点赞、不评论、不关注**；未部署连接器时该入口给出指引，用户仍可用自有文档或粘贴文本完成全部创作流程。登录失效时会明确提示，不会把失败显示成「没有数据」。

## 四、部署与复验

| 形态 | 启动方式 | 适用 |
| --- | --- | --- |
| Windows 免安装包 | 解压后双击「一键启动.cmd」，启动器选端口并打开浏览器 | 评审复现，无需安装运行时 |
| 源码部署 | 建虚拟环境装依赖，分别运行 `backend.api` 与 `backend.worker` | 二次开发与内网部署 |

源码部署：`python3 -m venv runtime/venv` → 安装 `requirements.txt` → 在 `.env` 设置 `DATABASE_URL` 与 `PUBLIC_ORIGIN`（真实模式另设模型密钥）→ 两个终端分别启动 `backend.api --port 8765` 与 `backend.worker` → 打开页面并用 `/health` 核对版本与数据库状态。API 与 Worker 必须共享同一数据库与模型配置，访问地址必须与 `PUBLIC_ORIGIN` 一致。新增核心表通过 `backend/migrations.py` 顺序迁移并校验校验和；更新前停止写入并备份数据库，不修改已应用迁移。不得把真实配置、Cookie、恢复码或数据库备份放入参赛代码包。

**数据升级与备份**：新增核心表通过 `backend/migrations.py` 顺序迁移并校验校验和；更新前停止写入并备份 PostgreSQL，已应用的迁移不原地修改、不删除迁移记录强行降级。资料更新保留旧版本，移出资料库仅排除新检索、不抹除旧任务证据；彻底删除个人数据按部署方策略执行——本机版直接删除 `data` 目录，内网版按数据库备份与留存策略处理。

工程复验：使用独立测试 schema 运行 `python -m unittest discover -s tests -v`（未配置 `TEST_DATABASE_URL` 导致的跳过不算通过）；交付基线在 SQLite 路径上的实测为 1189 项中 955 通过、234 条件跳过、0 失败 0 错误，前端 `node --test` 256 项全部通过。评测框架可离线自检：`scripts/evaluation_bench.py --self-check`，不调用模型、不产生费用。

## 五、故障处理

| 现象 | 处理方式 |
| --- | --- |
| 无法连接网站 / 已排队但不执行 | 确认 API 已启动、端口与地址正确；确认 Worker 与数据库运行且两进程配置一致 |
| 会话过期、写入被拒绝或版本冲突 | 刷新后重新登录并核对访问地址，不绕过 CSRF 与来源检查；重新载入任务检查最新稿件后再次审核 |
| 资料检索无结果或不像语义检索 | 检查账号、资料有效状态与「资料用途」；未提供本地向量模型时按词项检索，界面与任务快照会标注实际引擎 |
| 无法连接小红书 / 网页读取失败 | 确认连接器已启动且登录有效，未部署时改用自有文档；网页读取检查公开可访问性，不将摘要当正文 |
| 模型输出错误、预算不足或用量未知 | 查看失败阶段与用量并修正输入；用量未知时先人工核对供应商账单，不自动重发 |

**恢复说明**：Worker 重启后可在旧租约（30 秒）过期后领取任务；已保存节点与已接收响应可复用，取消后迟到结果不能提交新稿件。电脑关闭时任务暂停，需重新启动数据库、API 与 Worker——持久化不等于服务永不中断。

如需异地演示，开放前须完成：HTTPS 终结、不少于 16 位的注册邀请码、最小权限数据库身份、进程托管与自动重启、日志与告警、备份恢复演练、外部设备连通性验证；并用 `/health` 与一次模拟任务验证界面、后台执行与人工确认全链路。
