# 有迹技术方案

AI+软件创新 | 团队编号 47191919 | 软件版本 0.7.0

作品名称：有迹。完整定位：面向有一定内容基础、希望推广产品的小品牌博主的多智能体内容与运营助手。

本软件将账号定位、资料检索、内容创作、审核返修和运营复盘连接为可追踪的网页工作流程。用户保留修改和最终确认权，系统保存资料来源、稿件版本与执行记录。当前已实现本机网站、四角色创作、账号运营记录和持久后台执行；公网交付、真实平台接口与规模化内容质量评测仍有待完成。

文档更新日期：2026年10月4日。已有功能基线：441359e，本轮完善于2026年10月4日。9月21日ca8b327的源码快照和169/174项测试保留为历史记录；最新已完成的真实调用、下载与540项Python/101项Node回归摘要见docs/REAL_WORKFLOW_ACCEPTANCE_20261004.md。本轮M185真实运行、人工采用、导出和普通AI单次生成单列于配套测试报告；5人反馈尚未收集，不预填结果。

## 一 产品概述与定位

### 1.1 背景与问题

个人创作者的一次内容生产不仅包含写正文，还涉及判断目标读者、筛选资料、选择角度、修改表达和审核事实。持续运营还需要保持账号定位，并把历史作品与指标用于下一次决策。将这些操作分散在聊天窗口、文档和表格中，会增加上下文重复整理与版本核对的负担。

本项目保留原有账号、创作、资料、作品与复盘结构，收紧首要场景：小品牌博主已有产品特点，却不知道怎样表达才能吸引合适的客户。系统将产品特点连接到目标人群的困扰、同类选择理由和使用场景；推广目标为促成进一步了解或咨询，阅读和粉丝作为辅助观察。护肤品只是讨论中的例子，产品不限定品类。该定位尚无商业用户试点或市场规模调查支持。

### 1.2 产品目标与交付范围

系统帮助用户将已有材料转化为可审核的内容，并保留每次生成、返修和人工决定的依据。产品通过网页使用，核心 AI 能力为第三方大模型推理；项目自建资料检索、角色协作、版本守卫、调用预算与运营经验复用机制。

当前交付文字稿件、脚本、Markdown、中文PNG图卡、无声图文MP4及分镜字幕。图文视频是文字图卡组成的真实视频文件，不是AI绘画、配音或真人素材自动剪辑。软件不承诺爆款概率，不把创作完成视为平台发布成功。真实发布仍由用户在平台操作，发布信息和指标由用户回填。

## 二 技术架构与创新

### 2.1 五层架构与部署关系

[[architecture]]

界面负责需求输入与执行展示；编排层决定下一步与人工暂停；四个角色承担内容任务；工具层连接模型及资料；数据层保存账号、证据、稿件和审计记录。五层是职责划分，不要求部署五套服务器。

网站由 FastAPI 提供接口与静态页面。浏览器提交后台任务后轮询状态，独立 Worker 从 PostgreSQL 队列领取任务并运行 LangGraph。业务 Run 是权限、预算和批准的依据，图检查点只保存执行游标，不得覆盖业务约束。

### 2.2 技术选型

| 技术 | 本项目用途与选择原因 |
| --- | --- |
| Python 3.12 与 FastAPI | 实现 API、资料处理和模型适配；结构化服务边界便于测试 |
| 原生 HTML CSS JavaScript | 支撑现有工作台与任务状态展示，保持迭代路径简单 |
| PostgreSQL 与事务 | 保存用户和任务数据、队列及检查点；SQLite 保留本机兼容路径 |
| LangGraph | 表达并行角色、阶段推进、返修及人工中断；额外业务守卫由项目实现 |
| DeepSeek 与统一调用入口 | 利用现成语言模型进行生成与审核，保存模型路由、输入和用量信息 |
| BM25 | 首版采用可解释的关键词排序，无新增嵌入模型费用 |

主要锁定版本为 FastAPI 0.141.1、LangGraph 1.2.11、PostgreSQL checkpointer 3.1.2、psycopg 3.3.6；完整依赖以 requirements.txt 为准。版本号描述当前构建，不代表供应商最新版本。

## 二 技术架构与创新 续

### 2.3 四角色协作与人工决定

[[workflow]]

受众洞察与素材研究基于同一账号和证据快照并行执行。两支结果汇合后，内容角色依次生成策略、提纲、开头、标题和正文。主编角色输出检查结果和修改意见；返修仍交回内容角色。用户改稿或改选标题产生新版本，必须复审后才能确认。

### 2.4 项目贡献与差异化

第一，共享证据快照使研究、写作和审核引用同一份原文与版本。来源字段和逐字引用检查可以发现不存在的引用，但无法自动证明来源真实或语义推断正确。

第二，人工批准与稿件、审核、快照及哈希关联。页面确认不是唯一防线，后端事务拒绝旧版本、过期审核和伪造批准，使用户编辑不会被迟到结果替代。

第三，执行恢复与费用边界共同设计。已提交节点不重复应用，已收到响应可以复用；请求发出后响应丢失则停止并标记用量未知，避免恢复流程自动再次收费。

第四，运营建议需要用户采纳后才能复用，且限定账号、平台与来源模式。指标修正或经验撤销会使相关分析、经验或周计划失效，旧任务快照仍保留审计。

这些是应用机制与工程实现贡献。大模型、BM25 和 LangGraph 均为既有技术；本项目未训练基础模型，也不把角色数量作为创新效果证据。与普通单次生成相比是否减少修改、提高依据覆盖，仍需要同任务对照评测。

## 三 功能设计与实现

### 3.1 核心功能

| 模块 | 实现与使用边界 |
| --- | --- |
| 账号与历史 | 稳定 account_id 关联定位、历史和编辑偏好；网站身份与社媒账号分离 |
| 资料库 | 导入文本、Markdown、文本型 PDF，保存原文、版本、页码、位置和指纹 |
| 公开来源 | 用户主动搜索或读取网页；摘要与已读正文分开，不冒充平台实时热榜 |
| 四角色创作 | 模型以结构化输入输出协作，素材不足可补料，审核失败进入返修 |
| 编辑与确认 | 保存新稿、比较版本、复审或显式人工采用、确认准确版本并导出Markdown、中文图卡及无声图文视频 |
| 后台任务 | 任务队列、并行分支、检查点、租约及节点账本支持恢复 |
| 运营复盘 | 手工发布记录与指标、免费描述性计算；用户主动确认后可做一次真实AI解读，历史不足也给当篇观察与下一篇尝试建议 |
| 读者检查与试读 | AI检查正文是否回答作者问题及材料是否支持；真实读者逐人反馈，AI模拟不进入真人历史 |

### 3.2 数据和辅助功能

网站用户拥有自己的账号和资料空间，业务读写按 owner 与 account_id 隔离。登录会话可撤销，修改操作验证 CSRF、来源及版本。恢复码只保存哈希，重设密码会撤销旧会话。

资料更新保留旧版本，移出资料库仅排除新检索，不抹除旧任务证据。任务包含上下文、分支结果、阶段产物、稿件和审核记录。运营分析保存依赖的指标标识，支持数据修正后的失效传播。当前部分业务使用 JSON 聚合存储，不宣称所有领域对象已完成关系化拆表。

### 3.3 扩展方案

模型调用已集中到 Calls 与路由适配层；增加供应商需实现适配器并通过相同契约测试。检索未来可评估混合检索，但须先建立检索样本。平台 OAuth、发布和指标接口须在取得适用授权后接入。多模态生成、OCR 和高并发优化属于后续范围，不列为当前成品功能。

## 四 开发测试与部署 续

### 4.4 本地部署

评审复现环境需要 Python 3.12及以上、PostgreSQL 和浏览器。安装 requirements.txt 后配置专用数据库与 PUBLIC_ORIGIN，分别启动 backend.api 和 backend.worker；默认网站地址为 http://127.0.0.1:8765。详细命令、配置与故障处理见配套软件说明书。

API 与 Worker 共用数据库和模型配置。浏览器关闭后 Worker 可继续；电脑关闭期间不会执行。数据库使用独立账号及最小权限，密钥仅放服务器环境。迁移前备份数据库，已应用迁移不原地修改。公网运行还需 HTTPS、邀请码、进程托管、备份恢复与外部设备验收，目前未完成公网部署。

## 五 应用价值与展望

### 5.1 应用场景

本轮演示统一使用罗技M185无线鼠标的官方公开介绍作为案例：目标读者为第一次选购日常学习用鼠标、经常携带笔记本到教室或图书馆的大学生。以公开资料支持的连接方式、外形和使用场景组织内容，不补造当前售价、竞品参数或实测体验。该案例用于验证资料到成稿、确认和导出路径，不是已签约品牌客户，也不证明有真实销售线索。持续运营时，用户手工记录真实作品和同窗口指标，决定是否采纳下一篇尝试建议。

上述流程体现产品用途，不是已经开展的真实商业试点。仓库衣橱账号为虚构演示数据，课程资料整理为虚构输入的真实模型试运行，均不能作为真实账号增长证明。

### 5.3 市场与竞争分析

目标需求集中在资料可靠性、账号表达一致性和持续迭代。通用对话工具解决文本生成，内容编辑工具解决排版，运营管理工具侧重记录与执行；这些是比较维度，不代表对所有同类产品的能力判定。项目拟通过可追踪的协作和人工控制形成差异，尚未测得用户付费意愿、市场规模或商业收入。

### 5.4 成果与后续目标

当前成果为本机可运行的 AI 创作与运营软件及可恢复执行基础。下一阶段先完成真实模型对照评测和少量目标用户试用，再完成外部可访问的演示交付。评测记录人工修改时间、采用率、无依据陈述、任务成功率及费用，保留失败样本。平台接口、语义检索和媒体生成根据实测需求推进，不提前承诺传播效果。

项目尚无真实用户收益、专利或软件著作权证据随附。资料原文、第三方依赖与模型服务分别遵守相应授权；上线前仍需完善用户数据删除、留存和授权说明。
