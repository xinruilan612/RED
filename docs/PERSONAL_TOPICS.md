# 可修改账号定位的图文选题适配

入口：更多工具 → 选题潜力。读取当前账号的定位和受众，可自由填写任何领域；保存同步账号档案；定位或受众变化时递增档案版本。账号切换清空待比较内容，迟到结果不会串到另一个账号。

## 使用

1. 选择运营账号，确认或修改定位与目标受众。
2. 输入1–5个候选标题、内容，可分别上传JPG/PNG/WebP封面（每张3MB以内）。点击比较。
3. 查看匹配顺序和引用的历史作品，下载比较报告或将选题带入创作。
4. 历史来自“账号档案与历史”中自己的已发布记录，可在本页给历史补充封面。指标在“作品与复盘”录入。仅自然流量、图文、同账号同平台、同观察窗口的数据用于热度估计。缺指标作品仍可做内容参考。
5. 高级设置可调整文字、图片、定位参考权重，参考篇数，24/72小时与阅读/点赞/收藏/评论目标。修改后重算，不沿用旧结果。

## 真正实现的部分

Chinese-CLIP 在本机生成归一化512维中文文字和图片向量。长文分块，不静默丢弃尾部；图片验证格式、像素、体积，校正EXIF方向，转换RGB。网页中的候选封面仅用于本次处理；历史封面只保留向量、模型名、哈希，不保留原图。

定位、候选图文、当前账号历史进入带权相似检索。历史缺图片时使用跨模态匹配，不会把图片丢弃。参考贡献通过过去样本的留一参考误差变化衡量，有负贡献证据的参考被剔除；没有回测证据的参考明确不声称已验证有效。

适配算法是 `skapp_inspired_personalized_kernel_v1`：借鉴SKAPP的个性化检索、参考筛选思想，使用可解释核回归，**不是原SKAPP的RRCP/图网络，也没有把公开基准的768维权重套到中文512维特征上**。作者参考实现仍单独保留在SKAPP实验入口，不将两种结果混写。

历史按时间顺序回测，训练参考必须在目标发布前已经采集到指标。至少12条可比记录、5次历史回测且优于当时账号均值基线后，才允许显示实验参考估计；单候选还需至少3条有指标参考。上述数字是工程显示门槛，不代表统计充分。未满足时输出匹配建议，不输出假热度、爆款概率或置信度。当前参数上的回测不是独立前瞻验证。

没有跨账号借用历史，没有自动爬取平台，没有调用收费大模型。来源是用户录入，未独立核实。真实流量改善仍需发布后验证。

## 安装与运行

在项目根目录，用Python3.12创建独立环境（已有SKAPP环境可复用）：

```sh
python3.12 -m venv runtime/skapp/venv
runtime/skapp/venv/bin/pip install -r requirements-topics.txt
runtime/skapp/venv/bin/python scripts/setup_topic_model.py
runtime/venv/bin/python scripts/local_dev.py start
```

安装命令主动联网下载固定模型版本；网站处理图文时 `local_files_only=True`，不联网上传内容。官方仓库仅提供PyTorch权重，安装使用 `torch.load(weights_only=True)` 安全加载后转为safetensors；推理只读取safetensors。固定revision与文件指纹存于runtime目录。

模型：[OFA-Sys/Chinese-CLIP](https://github.com/OFA-Sys/Chinese-CLIP)，[官方模型说明](https://huggingface.co/OFA-Sys/chinese-clip-vit-base-patch16)，固定版本 `36e679e65c2a2fead755ae21162091293ad37834`。尊重上游许可，非本项目原创预训练模型。
