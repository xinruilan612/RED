有迹教师 Windows 便携包：第三方组件说明
核对日期：2026-10-11

本包默认使用本地 SQLite，不要求老师安装 PostgreSQL。
随包保留原项目已经测试过的 PostgreSQL 驱动依赖，不会因此自动连接数据库。
第三方组件按各自许可证提供，不将整个依赖集合统一声明为 MIT。

一、Python 与依赖文件

Python 为 python.org 官方 Windows x64 embeddable 私有运行时。
运行时的精确版本、文件 SHA-256 以随包 manifest 为准。
保留 python/LICENSE.txt 及官方运行时随附的第三方版权通知。
第三方 Python 包位于 python/Lib/site-packages/，其 .dist-info 目录中的
METADATA、LICENSE、licenses/、NOTICE 等仍与依赖一同保留。
完整依赖及版本以随包依赖清单和 METADATA 为准。

对应源码获取入口：
  https://github.com/psycopg/psycopg/tree/3.3.6
  https://github.com/psycopg/psycopg/archive/refs/tags/3.3.6.tar.gz

动态库；保留它们的原文件名及目录关系，不从系统目录提取替代 DLL。
其上游分别为 PostgreSQL 与 OpenSSL：
  https://www.postgresql.org/about/licence/

这些底层组件及驱动仍适用其原许可证，而不是本项目自定义许可。

使用者可依各组件许可证研究、修改及替换这些开源库。本项目不额外禁止
为了调试这些库的修改而进行的逆向工程。替换前应停止本程序，备份自己的
数据，再使用兼容 Windows x64 / Python 3.12 的库及配套动态依赖，保留其
元数据、许可证和原有包目录；替换后需重新验证启动与所用功能。
