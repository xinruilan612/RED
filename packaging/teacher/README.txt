一、打开方法（Windows 10/11，64位 x64）
1. 右键ZIP → 全部解压。建议解压到本机NTFS磁盘的桌面或 D:\Youji，不要直接在压缩软件内运行；FAT/exFAT U盘可能不支持密钥文件的私密权限。
2. 双击“一键启动.cmd”，无需安装Python、PostgreSQL或Node，也无需管理员权限。
3. 保留启动窗口，等待浏览器打开；未自动打开时，复制窗口显示的 http://127.0.0.1:端口 地址。
4. 首次在网页注册自己的本地测试账号。不要使用重要网站的密码，并妥善保管恢复码。
5. 使用后在启动窗口按 Ctrl+C 退出。关闭网页不会关闭后台；直接关闭启动窗口也会停止本包进程。

二、建议5分钟体验顺序
1. 进入资料库，将随包“示例产品资料.txt”上传或复制粘贴；点击预览、返回修改、确认入库。
2. 在资料库搜索“35 mL”核对检索依据。
3. 进入创作工作台，填写主题“介绍示例保湿乳的产品信息与使用注意”。
4. 先选免费模拟练习，查看四角色过程、草稿、审核和人工确认；此模式不是模型生成效果证据。
5. 需要真实AI时，在“模型连接”选择厂商，填写自己的API Key、接口地址和模型，按页面提示测试，再明确选择真实创作。
6. 在稿件中提出修改要求、检查引用与事实、确认后导出。确认稿件或手动归档不代表平台发布成功。

三、数据与费用
- 首次运行会在包目录创建data，里面保存本机账号、资料与任务。原始ZIP不含个人数据库、密钥或浏览器登录状态。
- 包内不附作者API Key，不附已登录的小红书账号，不自动抓取、发帖或购买服务。
- 免费练习不收费。真实模型、联网研究需网络及相应配置/授权；供应商可按自己的标准收费。
- 保存密钥后仍需测试连接。支持的协议/预设不代表所有厂商及所有模型都已真实验证。
- 停止程序不等于取消已保存任务；若开启过真实任务，请先在网页取消，否则下次启动后台可能继续已授权任务。
- 不要把使用过的整个目录直接发给别人：它可能含你新增的资料和加密凭据。分发请使用原始未运行ZIP。
- 备份时先关闭启动窗口，再整体备份data和app/runtime（若产生）。不要删除数据库排查错误。

四、遇到问题
- 没弹网页：先看启动窗口状态，再手动打开它显示的地址；不要沿用别人电脑上的localhost地址。
- 端口被占用：启动器会尝试后续端口，不会结束其他软件。已启动时先切回原窗口。
- 无法写文件：解压到自己的桌面或用户文档目录，不要放Program Files、只读目录或直接在ZIP里启动。
- 系统安全软件提示：先核对压缩包SHA-256及来源，不要关闭杀毒软件或绕过学校安全策略；受管电脑可请管理员确认。
- 页面显示缺少模型：这是未配置，不是数据库故障。用免费练习，或在页面内设置自己的模型连接。
- 模型报错：根据网页提示核对Key、余额、模型名称、接口协议；用量不明确时不要反复重试。
- 小红书/搜索不能获取：本包没有附带已登录连接器；可以使用自己的文本或文档入库，不会伪造实时数据。
- 其他故障：保留启动窗口提示与data中的日志，分享前去除个人信息，不要发送API Key或完整data目录。

五、评审边界
- 这是Windows本地软件运行包，不是公网网站；老师可在自己的电脑上运行。无需部署云数据库。
- 苹果macOS不能双击本包的Windows程序。app目录保留源码，跨平台开发需另行准备Python环境；未进行原生Mac验收。
- 内置基础依赖与关键词RAG，不包含大体积BGE模型、OCR、视频/图像生成或外部小红书采集服务。
- 测试环境为本机干净解压目录，不等同新装Windows虚拟机或所有型号电脑。
- Python及第三方依赖许可证保留在python目录，补充说明在app/packaging/teacher/THIRD_PARTY.txt。公开评审版仅供本机评审；上线前应另做运行时安全更新与生产部署验收。
- 这是软件交付物，不等于已完成赛事报名/材料提交。视频、技术方案、答辩材料及学校补充要求仍需按正式通知提交。

六、源码与校验
- app：可编辑源代码、测试、依赖版本、设计说明；历史文档具有日期，当前能力以docs/CONNECTED_CREATOR_STATUS.md及本包说明为准。

- 一键启动.cmd：唯一推荐的普通评审启动入口。其他源码部署脚本供开发者参考。
